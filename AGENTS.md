# Лунора — правила агента (AGENTS.md — универсальный источник, читается в каждой сессии)

Мультисистемный астрологический оракул — Telegram Mini App. Ядро отличия — **«считаемость»**: расчёт по карте — факт, интерпретация — разговор. Разборы по 4 системам (западная, ведическая/Джйотиш, Ба-Цзы, нумерология).

## Загрузочная последовательность (читай ровно это, в этом порядке)
1. `docs/CURRENT_STATE.md` — где мы (источник правды).
2. `docs/current/ROADMAP_STATUS.yaml` — текущий уровень/гейт/слайс.
3. Карточка текущего слайса (в `docs/05_roadmap.md`/`docs/grillmax/16_roadmap.md` или `docs/current/`).
4. `docs/current/WORKLOG.md` — что уже сделано внутри слайса, следующий шаг.
5. Только нужный reference-модуль из `docs/00_index.md` (не весь архив).
6. Первый заход в проект — `docs/LUNERA_STANDARDS.md` целиком.

Дальше — работай над **текущим слайсом**, не расширяя scope и не открывая следующий гейт.

## Фаза стройки (L1+): дисциплина слайса
- Веди `docs/current/WORKLOG.md` **на каждом шаге** (append-only): сделал X · следующий шаг · микрорешение «X, потому что Y». Состояние — в файле, не в контексте.
- **PASS слайса = зелёный `make verify`** (и `make slice-check`), а не «по-моему готово».
- Статус правь только в `docs/current/ROADMAP_STATUS.yaml`; `ROADMAP_BOARD.md` не трогай руками — генерируется (`make board`).
- Закрыл слайс → close-record в `docs/gates/` + запись в `docs/changelog.md` + обнови `CURRENT_STATE.md`.

## Жёсткие правила проекта (из Discovery — не нарушать)
1. **Фронтенд строго token-driven (ADR-003).** Цвета/отступы/шрифты — из `docs/grillmax/tokens.json`; экраны — из переиспользуемых компонентов; **ни одного захардкоженного стиля**.
2. **Корректность ядра — тестами (test-first).** Каждый движок на golden-наборах (ошибки прототипа: пропуск Солнца, высшие по знаку, год Ба-Цзы на границе — `docs/grillmax/04_product.md`). Красный тест = не мёржим.
3. **Оплата: внутри Telegram — только Stars (`XTR`)** (D-121). СБП/ЮKassa — вне Telegram. Повтор оплаты ≠ второй платёж (идемпотентность).
4. **Приватность (152-ФЗ).** В аналитику и зарубежный LLM — без ПДн (в LLM только градусы+текст; в аналитику только события).
5. **Голос — на «вы»**, тёпло, без «предсказаний/магии/гарантий». Запрещённый словарь — `docs/grillmax/02_problem.md` §4.5.
6. **Бюджет LLM** — детерминированные интерпретации + LLM на синтез + дешёвая модель на прогнозы (R-05).

## Всегда (канон Lunera)
- Планирование ≠ авторизация; закрытие гейта не открывает следующий.
- Факты из git/CI, а не из отчётов и прошлых сообщений.
- Секреты не попадают в код, логи, чат (`.env`).
- Все документы и общение — на русском; к оператору по имени — **Антон**.

## Стек и команды
- Бэк: Python 3.12, FastAPI, aiogram 3, SQLAlchemy async, PostgreSQL, Redis, Caddy, Docker. Фронт: React 19 + TS + Vite (`frontend/`). Тесты pytest, линт ruff.
```bash
make verify                 # линт + тесты + дисциплина доков (PASS-вход)
make slice-check            # проверки текущего слайса
make board                  # перегенерировать ROADMAP_BOARD.md
docker compose up --build   # окружение
```
