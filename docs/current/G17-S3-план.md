## G17-S3a — адаптер Telegram Stars

### Офлайн-доказательство (в `make slice-check`, без сети)

Фейковые обновления aiogram (настоящий `Dispatcher.feed_update`, подменённая сессия Bot API,
которая записывает вызовы) + **настоящая PostgreSQL** (временный кластер или
`LUNORA_TEST_PG_DSN`), схема — через `alembic upgrade head`.

| Правило | Тест | Ожидание |
|---|---|---|
| **S2** | `pre_checkout_query` по валидному/невалидному заказу | всегда ровно один `answerPreCheckoutQuery`: `ok=True` при валидном заказе и цене в `XTR`; `ok=False` + `error_message` иначе (неизвестный заказ, чужой пользователь, другая сумма/валюта, уже оплачен, внутренняя ошибка) |
| **S1** | два `successful_payment` с одним `telegram_payment_charge_id`, последовательно и параллельно | один оплаченный заказ, один доступ; гарантия — уникальные индексы БД (`processed_events`, `payments.telegram_payment_charge_id`, `grants.order_id`), не проверка в коде |
| **S3** | цена при создании инвойса; платёж на другую сумму/валюту | `price_xtr` снимок заказа = цене каталога в момент инвойса, `createInvoiceLink` с `XTR` и одной позицией; несоответствие → доступа нет, платёж `reconcile_needed` |
| **S4** | `successful_payment` потерян, восстановление | сверка по `getStarTransactions` (заглушка) находит платёж и засчитывает один раз, повтор сверки и запоздалое обновление — no-op |
| **S5** | возврат | `refundStarPayment` вызывается один раз, только на полную сумму (параметра суммы нет); повторный возврат — no-op без вызова API, доступ снят |

### Схема (миграция 002)

`star_orders` (снимок цены в `XTR`, `CHECK currency='XTR'`, `CHECK price_xtr>0`) ·
`star_payments` (`UNIQUE telegram_payment_charge_id`) · `star_processed_events`
(`UNIQUE (kind, event_key)`) · `star_grants` (`UNIQUE order_id`) · `star_refunds`
(`UNIQUE payment_id` — один полный возврат на платёж). Прототипные `payment_orders`/
`entitlements` не трогаем (единый `PaymentPort` с ЮKassa — позже, §2.4a вне scope).

### Живой смоук (вручную, с Антоном, вне CI)

Сначала тестовая среда Telegram (`/bot<token>/test/…`, без реальных звёзд), иначе 1 ⭐ в
боевой с возвратом. Протокол — `docs/current/spike/payment_smoke.md` (id платежа без ПДн).
Агент сам смоук **не запускает**.

### Вне scope S3a

ЮKassa/СБП (§2.4a); чеки/налоги по Stars (юрист+бухгалтер); каталог реальных цен (ПРАЙС §5);
авто-возврат дубля и `paid_late` (§4) — фиксируем состояние и алерт, сам авто-возврат — при
продуктовом переносе; частичный возврат Stars не существует (§3.6).
