# `agent-log/` — следы исполнителей

По одному файлу на задачу. Пишет их сам исполнитель в своей ветке: ход работы, спорные места,
принятые решения, доказательство «красным» и итоговые проверки. Ревьюер эти файлы не читает —
слепое ревью оценивает артефакт, а не отчёт.

| След | Задача | Что закрывает |
|---|---|---|
| [S3b-01.md](S3b-01.md) | Приватность пакета, уходящего в модель | сборка вынесена в чистую функцию, 25 тестов |
| [S3b-02.md](S3b-02.md) | Гард дрейфа порогов | 27 тестов на дрейф в обе стороны |
| [S3b-03.md](S3b-03.md) | Чекер `llm_cost.py --check` | офлайн-валидатор артефакта, 31 тест |
| [S3b-08.md](S3b-08.md) | Дыры покрытия теста приватности | боевой путь `generate_response`, слой паттернов, якорь промптов, `service_text` |
| [S3b-09.md](S3b-09.md) | Портретный путь | приватность второго пакета, маршрутный уровень |
| [S3b-10.md](S3b-10.md) | Гард порогов, вторая волна | зелёное состояние пересчёта, узкая опора R-05, provenance |
| [S3b-11.md](S3b-11.md) | Валидатор схемы | fail-closed политика `additionalProperties`, инвариант ключевых слов |
| [S3b-12.md](S3b-12.md) | Гарды в гейте | `make slice-check-s3b` включает три набора и чекер |

Правило: след живёт, пока у него есть потребитель — ревьюер, критик и следующий исполнитель.
Приёмка и разбор находок — в карточке гейта [../G17-S3b-план.md](../G17-S3b-план.md).
