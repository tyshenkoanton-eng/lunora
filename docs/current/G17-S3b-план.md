## Кандидаты моделей (решение Антона)
Меряем представительный диапазон, чтобы Антон выбрал по цене/качеству:
- **Claude 5** (топовая линейка): `anthropic/claude-opus-5-5` (вау-эффект, §3.5-решение),
  `anthropic/claude-sonnet-5-5` (середина), `anthropic/claude-haiku-5-5` (дёшево) —
  точные slug/цены сверяем на день замера.
- **DeepSeek**: `deepseek/deepseek-chat` (V3, для синтеза; reasoner жжёт выход — не берём в база).
- **MiniMax** (опционально): текущий slug уточняем на день замера.

**Канал — OpenRouter**, как в рантайме (`config.py`: `llm_base_url=https://openrouter.ai/api/v1`,
OpenAI-совместимый `/chat/completions`). Один ключ, один хост, все три семейства. Это и есть
«посредник» из бюджета — см. «Открытые факты».

## Методика замера
1. **Данные без ПДн.** 5 синтетических карт A–E через `calculate(BirthData)` (вымышленные
   дата/место, имя «Тест»). Реальные градусы → реалистичные токены. Никаких ПДн в замер
   и в репо не уходит (152-ФЗ).
2. **Сценарии (3, как в схеме):**
   - `dialog` — один вопрос в диалоге (пакет `build_messages`), множитель 25 вызовов/сутки;
   - `document` — синтез документа «Мы с ним», множитель 1;
   - `forecast` — утренний прогноз, множитель 7 дней/мес.
3. **Сэмплы.** 5 карт × 3 прогона = 15 живых вызовов на сценарий на модель
   (~45 вызовов/модель). Из них — распределение себестоимости ОДНОГО вызова (median, p90).
   Множители (25/1/7) накладывает чекер сам — это НЕ число живых вызовов.
4. **Цена.** usage (`input_tokens`/`output_tokens`, с кэшем, как отдаёт OpenRouter) ×
   актуальная цена модели × курс USD→RUB на день замера × наценка посредника (замеряем
   фактическую у OpenRouter, не постулируем ×1,5).
5. **Артефакт.** `docs/current/spike/llm_cost.json` по схеме — для **выбранной** модели
   (чекер проверяет один файл). Полная сравнительная таблица по всем кандидатам —
   в close-record. `llm_cost.py --check` зелёный на выбранной модели.

## Разбор расхождений бюджета (офлайн, до трат — задача S3b-01)
Внешний документ указывал на нестыковки; проверяем каждую:
1. **§3.1 vs §3.5 — одна Haiku, разные числа** (10 ₽ vs 15 ₽/сутки). Зафиксировано в
   `known_inconsistency` порогов: §3.1 без наценки/кэша, §3.5 с кэшем и ×1,5. Решение
   по порогу — за Антоном (ослаблять задним числом нельзя).
2. **Курс устарел** (83,59 ₽ на 2026-08). Берём официальный курс ЦБ на день замера.
3. **Цена Sonnet устарела.** Берём актуальный прайсинг Claude 5 на день замера.
4. **«Посредник ×1,5».** Код ходит в **OpenRouter** (подтверждено: `config.py`). OpenRouter —
   не российский реселлер; его реальная наценка ≠ ×1,5 (меряем фактическую). 152-ФЗ:
   зарубежный LLM допустим только без ПДн (градусы+текст) — соблюдено.
