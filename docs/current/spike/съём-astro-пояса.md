# Форма съёма эталонов поясов — astro.com (G17-S1)

**Кто:** Антон · **Зачем:** второй независимый источник смещения UTC для golden-кейсов слоя `timeplace` (`ARCHITECTURE.md` §6.3). Наш первый источник — IANA 2026f. Заполненная строка + скриншот = основание перевести кейс в `active`.

Связано: карточка [G17-S1-план.md](../G17-S1-план.md), раздел «Время и часовые пояса».

## Перед съёмом

1. Прочитать условия использования astro.com (П-12). Съём ручной и однократный, без автоматизации.
2. Наших значений смещения в форме нет намеренно: эталон снимается вслепую, чтобы не подгонять.
3. Путь: astro.com → «Бесплатные гороскопы» → «Карта рождения, асцендент» (или «Расширенный выбор карт») → ввод данных. Имя — любое вымышленное (например «Тест»), пол любой.

## Как снимать одну строку

1. Ввести город из колонки «Место» (выбрать именно этот город из подсказки атласа), дату и время из строки.
2. На странице карты найти строку вида «UT/GMT …» и пояс («Zone», например `3h E`, `+4:00`, «DST» / «летнее»).
3. Вписать в колонку «Смещение astro.com» как `+HH:MM` (восточнее Гринвича — плюс), а в «Пометка атласа» — как сайт называет режим (например `MSD`, `zone -3h, DST`).
4. Скриншот области с датой, местом и UT сохранить как `<ID>.png` и прислать (лягут в `tests/golden/evidence/`).
5. Если атлас предлагает выбор или пишет предупреждение — переписать текст предупреждения в «Пометка атласа».
