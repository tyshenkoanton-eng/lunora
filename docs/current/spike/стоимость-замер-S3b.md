# S3b — живой замер стоимости LLM: таблица и вердикт

**Дата:** 2026-11-28 · Задача S3b. Канал — OpenRouter, себестоимость = фактический
`usage.cost` × курс 79 ₽/$ × наценка ×1,0. Синтетика A–E («Тест», без ПДн; к моделям —
только градусы+текст, 152-ФЗ). Пороги — `scripts/spike/llm_cost_thresholds.json`
(вариант **B** основной: §3.5 бюджета). Сырые данные — `llm_compare.json`, артефакт
чекера — `llm_cost.json`.

## Вердикт по порогам (вариант B)

**Чат-вопрос** (порог B: ≤ 3,01 ₽/вопрос, ≤ 75 ₽/сутки при 25 вопросах):
- **Opus 5.5 — НЕ проходит:** 4,73 ₽/вопрос (118 ₽/сутки). Причина — у Claude 5.5
  «мышление» нельзя выключить, и оно тарифицируется как выход. Для массового чата дорого.
- **Sonnet 5.5 — проходит:** 2,11 ₽/вопрос (53 ₽/сутки). И по цене, и по качеству (слепой
  тест на карте оператора — тон на уровне Opus) — **рабочая модель чата**.
- Haiku (0,10 ₽), DeepSeek (0,07 ₽), GPT-5.6 (0,99 ₽) — все в пороге с большим запасом.

**Портрет-документ** (порог A: ≤ 10 ₽; в B — не задан): все модели проходят с запасом
(макс. Opus 2,26 ₽). **Opus 5.5** для премиум-документа — комфортно (цена ничтожна против
цены продукта 490–1490 ₽).
- Открытый риск — будущий «тяжёлый документ» §3.1 (вход ~4к / выход ~15к, в коде ещё НЕТ):
  проекция на Opus ≈ 25 ₽ > порога документа 10 ₽ (вариант A). Для таких — дешёвая модель
  или отдельный порог. Точную цифру снимем, когда появится сам продукт.

**Прогноз** (порог: ≤ 1 ₽/юзер·месяц, R-05 «дешёвая модель»):
- Измеренное (чат-формат) на Haiku 0,08 ₽/вызов — при 30 прогнозах/мес это ~2,3 ₽/мес,
  формально выше 1 ₽. НО это пессимизм харнесса (тяжёлый выход). Реальный прогноз на Haiku
  (короткий выход ~200 токенов) ≈ 0,013 ₽/вызов → **~0,4 ₽/мес/юзер — в пороге**.
- **Рекомендация: Haiku 5.5** для прогноза (R-05 выполнен), с оговоркой: точную цифру снять
  на боевом лёгком промпте прогноза (`forecast/generate`), не на чат-харнессе.

## Находки замера (в close-record)

1. **Claude 5.5 «мышление» не выключается** (Opus/Sonnet → HTTP 400 на
   `reasoning.enabled=false`; только Haiku можно). По умолчанию съедает бюджет выхода.
2. **Боевой `client.py` багует на Claude 5.5:** `max_tokens=1000` без управления ризонингом
   → `finish_reason=length`, `content=None` (пустой ответ, токены тарифицируются). Чинить
   отдельной задачей (слой llm). Рабочий конфиг замера: `reasoning:{effort:"low"}` +
   `max_tokens=3000`.
3. **Наценка посредника ≈ ×1,0** (не ×1,5): OpenRouter отдаёт фактический `usage.cost`.
4. DeepSeek V3.2 нестабилен по сети (дважды `IncompleteRead`) — как ценовой пол годится,
   как рабочая модель — риск надёжности.

Все поправки бюджета — ВНИЗ от оценки §3.1/§3.5 (курс, подешевевший Claude, наценка ×1,0).
Себестоимость выбранного набора комфортно в пределах бюджета на каждом уровне.
