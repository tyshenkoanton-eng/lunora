# Какие модели нужны Луноре: карта «задача → модель» (S3b, исследование)

**Дата:** 2026-11-28 · Для Антона, в помощь выбору. Цены — с публичного OpenRouter
`/api/v1/models` и Anthropic (2026-11-28). Это рекомендация под проверку живым замером
(стоимость + небольшой слепой тест качества на русском), не финальное решение.

## 1. Где у нас вообще работает LLM
В Луноре расчёт по карте — детерминированный (движки), LLM только на **синтез текста**.
Реальных точек вызова три (всё идёт через один `_call_llm` → OpenRouter):

| Задача | Где в коде | Профиль | Критично |
|---|---|---|---|
| **Чат-диалог** (4 системы, тёплый разбор) | `llm/client.build_messages` → `generate_response` | ~500–700 вход / ~800 выход, 25 вопросов/сутки, платные пакеты | **качество разговора** (вау-эффект, §3.5), голос «на вы» |
| **Документ / портрет** (премиум-продукты 490–1490 ₽) | `interpret/portrait` | больше вход, выход до 1000 (будущий «тяжёлый» — до 15k) | **качество = ценность продукта** |
| **Утренний прогноз** (бесплатный слой) | `forecast/generate` | 2–3 абзаца, массово, ~1 ₽/мес/юзер | **цена** (R-05: дешёвая модель) |

Детерминированно (LLM **не** нужен и не планируется): расчёт карт, нумерология, имя,
safety-классификация вопроса (`llm/safety`), валидация формата (`llm/validator`).
ПДн в LLM не уходят ни на одном пути — рантайм-страж `llm/pii.py` (PR #24) блокирует пакет
с ПДн до сети (152-ФЗ).

## 2. По каким критериям выбираем — именно для Луноры
1. **Качество русского разговорного текста** — главное. Продукт — тёплый живой разбор на
   русском с культурным тактом и запретным словарём (без «предсказаний/магии/гарантий»).
   Это упирается в язык и тон, не в «умность» на кодинге/математике.
2. **Цена — вторична.** Маржа продуктов 87–94% (§3.2), себестоимость не ограничивает; даже
   топовая модель укладывается в бюджет (§3.5). Экономить на модели там, где качество —
   ценность, смысла нет; экономить — на массовом бесплатном слое.
3. **152-ФЗ / юрисдикция.** ПДн не уходят (страж). Но провайдер — это ещё и доверие: Claude
   (США, Anthropic) vs DeepSeek/MiniMax (КНР). При равном качестве меньше политического риска
   у US-провайдера; при неравном — качество решает.
4. **Надёжность и отказы.** У Claude 5.5 есть классификаторы безопасности (могут вернуть
   `refusal`) — для оракула с кризис/здоровье/финансы темами это надо учитывать (есть
   серверный fallback). Единый провайдер = единый голос и проще эксплуатация.

## 3. Кандидаты (факты, не маркетинг)
Цены USD за 1M вход/выход (2026-11-28):

| Модель | вход | выход | Русский | Замечание |
|---|---:|---:|---|---|
| **Claude Opus 5.5** | $4 | $20 | отличный | топ качества; адаптивное «мышление» тарифицируется (растит выход) |
| **Claude Sonnet 5.5** | $2 | $10 | отличный | баланс качество/цена, наш рабочий кандидат для чата |
| **Claude Haiku 5.5** | $0,10 | $0,50 | хороший | в ~10× дешевле старой Haiku 4.5; идеален для прогноза |
| **DeepSeek V3.2** | $0,26 | $0,38 | **под вопросом** | силён в общем ризонинге (≈GPT-5-high), но русского бенчмарка нет; V3.2-Exp в русском был хуже V3 |
| **MiniMax M3** | $0,30 | $1,20 | **не подтверждён** | заточен под код/агентность, 1M контекст; языки даже не указаны в карточке модели |

**Вывод по не-Claude:** DeepSeek и MiniMax дёшевы и сильны в технических задачах, но их
**русское разговорное качество не доказано** (у MiniMax — вообще не заявлено). Для продукта,
где ценность — именно русский тёплый текст, это главный риск. Держим их как **ценовой
ориентир и запасной вариант**, не как основу, пока качество не проверим вживую.

## 4. Рекомендация: карта «задача → модель»
Один семейство (Claude), три уровня по ценности задачи:

| Задача | Рекомендую | Почему |
|---|---|---|
| **Чат-диалог** | **Sonnet 5.5** (дефолт), Opus 5.5 — если слепой тест качества даст заметный выигрыш | качество/цена; при 25 вопр./сутки обе в бюджете (вар. B — 75 ₽/сутки) |
| **Документ/портрет** (премиум) | **Opus 5.5** | качество = воспринимаемая ценность продукта 490–1490 ₽; цена вызова (даже тяжёлый ≈25 ₽) ничтожна против цены |
| **Прогноз** (бесплатный слой) | **Haiku 5.5** | массово и дёшево (~$0,0005/прогноз), русский хороший, тот же голос; R-05 «дешёвая модель на прогнозы» выполнен |
| safety/имя/нумерология | детерминированно (как сейчас) | LLM не нужен |

**Простая модель в голове:** Opus — премиум-документы, Sonnet — чат, Haiku — бесплатные
прогнозы. Один провайдер (Claude) даёт единый голос, одну юрисдикцию (США), проще
эксплуатацию, и 152-ФЗ уже закрыт (ПДн не уходят). Цена комфортно в бюджете на каждом уровне.

**Где DeepSeek/MiniMax:** меряем DeepSeek V3.2 как «ценовой пол» (вдруг на прогнозе он
достаточно хорош и ещё дешевле Haiku — тогда кандидат на бесплатный слой). MiniMax пока
откладываем (русский не подтверждён, профиль — код, не разговор).

## 5. Что доказываем живым замером (S3b)
- **Стоимость** — по методике плана (usage × прайсинг), вердикт vs бюджет.
- **Небольшой слепой тест качества на русском** — 3–5 карт, те же пакеты, ответы Opus 5.5 /
  Sonnet 5.5 / Haiku 5.5 / DeepSeek V3.2 рядом; Антон смотрит тон, точность, запретный
  словарь. Это и решает чат-уровень (Opus vs Sonnet) доказательно, а не на вкус.
- **Нюанс «мышления».** У Claude 5.5 адаптивное мышление тарифицируется как выход и растит
  цену. Через OpenRouter (OpenAI-совместимый endpoint) мы его не настраиваем — идёт дефолт;
  при переходе на нативный Anthropic API можно крутить `effort`/выключать мышление и так
  резать цену чата. Замерим фактический выход, чтобы это увидеть.

## 5a. Запасной провайдер (на случай «если с Claude что-то случится»)
Два уровня устойчивости:

**Уровень 1 — архитектура уже готова.** Код ходит по OpenAI-совместимому endpoint
(`llm_base_url`/`llm_model` в config.py). Смена модели — **одна строка конфига, без правки
кода**; сам OpenRouter умеет авто-переключение между провайдерами. То есть «что-то с Claude»
= поменять строку модели, не переписывать систему.

**Уровень 2 — доказанный бэкап от ДРУГОГО вендора** (чтобы проблема именно Anthropic —
сбой, доступ, политика — нас не роняла). Через тот же ключ OpenRouter, сильный русский:

| Кандидат-бэкап | вход/выход $/1M | Независимость | На какой уровень |
|---|---:|---|---|
| **OpenAI GPT-5.6** (terra $2/$12; luna $0,2/$1,2) | — | США, не Anthropic | terra → чат/документ, luna → прогноз |
| **Google Gemini 3 Pro** ($2/$12; flash-lite $0,25/$1,5) | — | США, не Anthropic | pro → чат/документ, flash → прогноз |
| DeepSeek V3.2 ($0,26/$0,38) | — | КНР | дешёвый бэкап прогноза |

Предлагаю назначить **один вендор бэкапом на все уровни** (ровный голос) — рабочий выбор
**GPT-5.6** (terra для чата/документа, luna для прогноза) ИЛИ **Gemini 3 Pro**. Добавлю его
в замер — получим готовый, проверенный по цене и качеству запас.

**Стратегический вариант (по желанию) — отечественная модель** (YandexGPT 5 / GigaChat /
T-pro). Её нет в OpenRouter (нужен отдельный доступ/ключ), но она убирает риск зарубежного
провайдера целиком и усиливает 152-ФЗ (данные в РФ). Это отдельный трек, не для этого замера,
— но если цель «максимальная независимость от Запада», стоит оценить её отдельно.
