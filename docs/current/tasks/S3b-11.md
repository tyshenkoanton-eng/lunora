# S3b-11 · Валидатор схемы: fail-closed на `additionalProperties` + тест инварианта

**Гейт:** G17-S3b · **Карточка:** [../G17-S3b-план.md](../G17-S3b-план.md) · **Статус:** контракт записан по замечаниям ревью S3b-03 (З1, З2), подтверждённым критикой
**Способ:** `TASK_CONTRACT.md` · **Контур:** `EXECUTION_PROTOCOL.md` · **Ревью:** `REVIEWER_CHARTER.md`

TASK      : Довести валидатор артефакта до заявленной fail-closed политики и закрепить её тестом. Две части: (1) `additionalProperties` — значение обрабатывать явно: `false` — «лишние поля запрещены» (как сейчас); `true` — «ограничений нет» (легальная форма JSON Schema, отвергать её нельзя); **подсхема** (`dict`) — неподдерживаемая форма → ошибка; объектный узел **без** этого слова — тоже неподдерживаемая форма (сейчас `None is False`, и проверка молча не выполняется); (2) добавить регрессионный тест на сам fail-closed инвариант: копия схемы с неподдерживаемым ключевым словом в достижимом узле → ненулевой код выхода с внятным сообщением.
ВХОД      : `scripts/spike/llm_cost.py` (валидатор: `CONSTRAINT_KEYWORDS`, `ANNOTATION_KEYWORDS`, проверка `additionalProperties`), `scripts/spike/llm_cost.schema.json` (боевая схема — **read-only**), `tests/test_llm_cost.py` (текущие фикстуры схемы).
ГРАНИЦЫ   : Запись — `scripts/spike/llm_cost.py`, `tests/test_llm_cost.py`, `docs/current/agent-log/S3b-11.md`. **Read-only:** `scripts/spike/llm_cost.schema.json`, `scripts/spike/llm_cost_thresholds.json`, `Makefile`, `src/**`, `docs/grillmax/**`, `docs/current/ROADMAP_STATUS.yaml`.
            Поведение `--check` по существу не менять: код выхода 0 на артефакте в бюджете, 1 на битом/превышении; формат сообщений прежний.
ПРОВЕРКА  : (из корня рабочего каталога задачи — worktree)
            `PYTHONPATH=src /opt/dashboard/venv-lunora/bin/python -m pytest -q tests/test_llm_cost.py` — зелёный выход.
            `PYTHONPATH=src /opt/dashboard/venv-lunora/bin/python -m ruff check scripts/spike/llm_cost.py tests/test_llm_cost.py` — зелёный выход.
КРИТЕРИЙ  : (а) `additionalProperties: true` трактуется как «ограничений нет», лишние поля **проходят** — это легальная форма спецификации; (б) `additionalProperties` как подсхема → ошибка, а не молчаливый пропуск; (в) объектный узел без `additionalProperties` → ошибка с внятным сообщением; (г) неизвестное ключевое слово в достижимом узле → ошибка (поведение уже есть, теперь оно **закреплено тестом**); (д) тест-проверка инварианта «используемые слова ⊆ реализованные» должна ловить случай, когда в список «известных» добавлено слово без реализации; (е) «красным»: не менее трёх зафиксированных мутаций копии схемы, каждая роняет набор или даёт ненулевой код выхода.
СКИЛЛ     : python, json, pytest — только стандартная библиотека, новых зависимостей не добавлять.
РЕВЬЮ     : Слепой ревьюер: «валидатор действительно fail-closed, а тест не пустой». Безопасник — отдельный проход: «в тестовых копиях схемы нет ключей и реальных данных». Критик ревью — обязателен.
