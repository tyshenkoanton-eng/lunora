# S3b-08 · Тест приватности: закрыть дыры покрытия

**Гейт:** G17-S3b · **Карточка:** [../G17-S3b-план.md](../G17-S3b-план.md) · **Статус:** контракт записан по замечаниям ревью S3b-01 (З1, З2, З3) и находкам критики
**Способ:** `TASK_CONTRACT.md` · **Контур:** `EXECUTION_PROTOCOL.md` · **Ревью:** `REVIEWER_CHARTER.md`

TASK      : Добить покрытие теста приватности четырьмя правками в одном файле `tests/test_llm_privacy.py`: (1) тест, что боевой путь `generate_response` вызывает `build_messages` с правильными аргументами — заглушка `_call_llm`, сверка перехваченного payload на четырёх категориях вопроса; (2) параметризованный тест, что обобщённый слой детекции (`PII_PATTERNS`) ловит ПДн, которых **нет** среди маркеров фикстуры (дата «31.12.1999», ISO-дата, uuid, 9-значный id) — сейчас удаление любого паттерна не роняет набор; (3) якорь системной половины golden-фикстуры: правка `SYSTEM_PROMPT` или `SAFETY_ADDENDUM_*` сейчас оставляет набор зелёным — нужно, чтобы это было видно; (4) `service_text` должен брать сообщение карты, а не первое user-сообщение с маркером: враждебная история («## Вопрос» в реплике пользователя) сейчас отключает проверку карты целиком.
ВХОД      : `tests/test_llm_privacy.py`, `src/lunora/llm/client.py` (**read-only**), `src/lunora/llm/prompts.py` (**read-only**), `src/lunora/llm/safety.py` (**read-only**).
ГРАНИЦЫ   : Запись — `tests/test_llm_privacy.py`, `docs/current/agent-log/S3b-08.md`. **Read-only:** `src/**`, `scripts/**`, `docs/grillmax/**`, `docs/current/ROADMAP_STATUS.yaml`. Продуктовый код не трогать: все четыре правки — в тесте.
            Граница продукта сохраняется: слова пользователя (вопрос и история) не фильтруются и не проверяются на ПДн — проверяется служебная часть пакета.
ПРОВЕРКА  : (из корня рабочего каталога задачи — worktree)
            `PYTHONPATH=src /opt/dashboard/venv-lunora/bin/python -m pytest -q tests/test_llm_privacy.py` — зелёный выход.
            `PYTHONPATH=src /opt/dashboard/venv-lunora/bin/python -m ruff check tests/test_llm_privacy.py` — зелёный выход.
КРИТЕРИЙ  : (а) правка вызова `build_messages` в `generate_response` (потеря категории, потеря истории, перестановка позиционных аргументов) роняет набор — потеря аддендума безопасности и потеря истории не должны остаться незамеченными; (б) удаление **любого** паттерна из `PII_PATTERNS` роняет набор; (в) правка `SYSTEM_PROMPT` или любого `SAFETY_ADDENDUM_*` роняет набор; (г) история, содержащая «## Вопрос», **не** отключает проверку данных карты — ФИО из карты в таком случае должно быть найдено; (д) «красным»: не менее четырёх зафиксированных мутаций, каждая записана в agent-log с выводом pytest.
СКИЛЛ     : python, pytest — стандартная библиотека, новых зависимостей не добавлять.
РЕВЬЮ     : Слепой ревьюер: «дыры закрыты — каждая мутация роняет набор, тест не пустой». Безопасник — отдельный проход: «в фикстурах нет ключей, токенов и реальных ПДн». Критик ревью — обязателен.
