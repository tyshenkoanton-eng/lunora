# S3b-04 · Живой замер стоимости LLM на OpenRouter: три кандидата на одних картах

**Гейт:** G17-S3b · **Карточка:** [../G17-S3b-план.md](../G17-S3b-план.md) · **Статус:** контракт записан; решения Антона от 2026-11-26 — связка OpenRouter + модели Anthropic, объём замера, способ доставки ключа
**Способ:** `TASK_CONTRACT.md` · **Контур:** `EXECUTION_PROTOCOL.md` · **Ревью:** `REVIEWER_CHARTER.md`

TASK      : Провести живой замер стоимости LLM-синтеза по методике `docs/current/G17-S1-план.md` § «Стоимость» и записать фактический `usage` каждого вызова. Три сценария — `dialog` (25 вопросов из одной темы на карту), `document` (документ-синтез «Мы с ним»), `forecast` (утренний прогноз, 7 дней) — на картах A–E, каждый сценарий повторяется 3 раза, в артефакт идут медиана и p90 выходных токенов. Кандидаты (решение Антона, 2026-11-26): **Claude Haiku 4.5 и Claude Haiku 5.5 — полный объём (все 5 карт, 25 вопросов на карту в диалоге), Claude Opus 5 — на трёх картах (A, B, C)**, чтобы не жечь бюджет на самом дорогом кандидате. Ключ OpenRouter — один на всех трёх. Реализовать режим `--measure` в `scripts/spike/llm_cost.py` (сегодня его нет: скрипт умеет только `--check`) и записать артефакты.
ВХОД      : `scripts/spike/llm_cost.py` (режим `--check` — база для переиспользования валидатора и сверки с порогами), `scripts/spike/llm_cost.schema.json` (форма артефакта — **в этой задаче разрешена правка**), `scripts/spike/llm_cost_thresholds.json` (**read-only**), `src/lunora/llm/client.py` (`build_messages`, `generate_response` — как собирается пакет), `src/lunora/config.py` (`llm_api_key`, `llm_base_url`, `llm_model`), методика — `docs/current/G17-S1-план.md` § «Стоимость», пороги и формула — `docs/grillmax/05_business.md` §3.1/§3.5, карточка гейта — `docs/current/G17-S3b-план.md`.
ГРАНИЦЫ   : Запись — `scripts/spike/llm_cost.py`, `scripts/spike/llm_cost.schema.json`, `docs/current/spike/llm_cost.json`, `docs/current/spike/llm_cost-<модель>.json` (по одному на модель), `docs/current/spike/llm_cost.md` (человекочитаемый отчёт), `.env.example`, `docs/current/agent-log/S3b-04.md`. **Read-only:** `src/**`, `docs/grillmax/**`, `scripts/spike/llm_cost_thresholds.json`, `docs/current/ROADMAP_STATUS.yaml`, `Makefile`.
            **Ключ не попадает ни в репозиторий, ни в отчёт, ни в лог.** Оператор кладёт его на сервер файлом (`/root/.lunera-openrouter-key`, режим 600); код читает его оттуда и никогда не печатает. В `.env.example` — только имя переменной, без значения. Если ключа на сервере нет — **остановись и сообщи оркестратору, не подставляя ничего вместо него**.
            Правка схемы ограничена: `cards` в сценарии — `minItems` 5 → 3 (решение Антона: Opus измеряется на трёх картах из пяти; полный объём пяти карт обязателен для модели, выбранной в S3b-06, — это проверяется там, а не здесь). Больше схему не трогать: формат `verdict`, `pricing`, `usage`, `cost_rub` — как есть. Единица `cost_rub` — ₽ за **один вызов** модели по сценарию; периодные пороги получаются умножением на `calls_per_card`.
ПРОВЕРКА  : (из корня рабочего каталога задачи — worktree)
            `PYTHONPATH=src /opt/dashboard/venv-lunora/bin/python -m pytest -q tests/test_llm_cost.py` — зелёный выход (оффлайн-часть `--measure` тестируется без сети и без ключа).
            `PYTHONPATH=src /opt/dashboard/venv-lunora/bin/python -m ruff check scripts/spike/llm_cost.py` — зелёный выход.
            `PYTHONPATH=src /opt/dashboard/venv-lunora/bin/python scripts/spike/llm_cost.py --check` — на боевом артефакте код выхода 0, если он в бюджете, и 1, если вне; на артефакте вне бюджета — ненулевой код.
            `PYTHONPATH=src /opt/dashboard/venv-lunora/bin/python scripts/spike/llm_cost.py --check --artifact docs/current/spike/llm_cost-<модель>.json` — то же для каждого из трёх артефактов.
КРИТЕРИЙ  : (а) `usage` в артефакте — **фактический** из ответов API, а не оценка по формуле: в артефакте видно `input_tokens`/`output_tokens` по каждому вызову; (б) три сценария, `runs = 3`, `cards` — A–E для Haiku-пар и A, B, C для Opus, `calls_per_card` — 25 / 1 / 7; (в) `cost_rub` считается из фактического `usage` × цены модели × курса на дату замера; наценка «российский посредник ×1,5» **не применяется** — посредник OpenRouter (решение Антона, `ADR-002` D-112/D-114, `RISKS.md` R-15); (г) цены и курс записаны в артефакт с датой; (д) ключ не попал ни в один записанный файл: `grep -R` по артефактам, отчёту, `.env.example` и git-истории — ни одного вхождения значения ключа; (е) отчёт `llm_cost.md` содержит по каждой модели: ₽ за вопрос, ₽ за 25 вопросов, ₽ за сценарий, p50/p90 выходных токенов, долю кэша; (ж) «красным»: оффлайн-тест `--measure` падает без ключа и без сети, а не проходит молча.
СКИЛЛ     : python, httpx (уже в зависимостях проекта), json — без новых зависимостей.
РЕВЬЮ     : Слепой ревьюер: «цифры настоящие, ключ не утёк, артефакты проходят `--check`». Безопасник — отдельный проход: «в артефактах и отчёте нет ключа и реальных ПДн пользователей». Критик ревью — обязателен. **Решение о модели по качеству — за Антоном**, система готовит цифры.
