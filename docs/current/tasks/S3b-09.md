# S3b-09 · Портретный путь: приватность второго пакета, уходящего в модель

**Гейт:** G17-S3b · **Карточка:** [../G17-S3b-план.md](../G17-S3b-план.md) · **Статус:** контракт записан по находке критики ревью S3b-01 («второй пакет в модель не покрыт»)
**Способ:** `TASK_CONTRACT.md` · **Контур:** `EXECUTION_PROTOCOL.md` · **Ревью:** `REVIEWER_CHARTER.md`

TASK      : Закрепить тестом приватность второго пути, который тоже уходит в модель: портрет (`GET /api/portrait/{user_id}` → `build_portrait_prompt(blocks, chart_data)`). Живой утечки нет — по коду в пакет портрета идут только тексты интерпретаций, год зверя, стихия дневного мастера и число жизненного пути, — но гарантия «в пакете нет ПДн» на этом пути **не закреплена**, и следующая правка может его открыть.
ВХОД      : `src/lunora/interpret/portrait.py` (**read-only**), `src/lunora/api/routes.py` (**read-only**, вызов `/portrait/{user_id}`), `src/lunora/llm/prompts.py` (**read-only**), требование приватности — `docs/current/G17-S1-план.md` § «Приватность (152-ФЗ)».
ГРАНИЦЫ   : Запись — новый `tests/test_llm_portrait_privacy.py`, `docs/current/agent-log/S3b-09.md`. **Read-only:** `src/**`, `tests/test_llm_privacy.py` (файл занят задачей S3b-08 — не трогать), `scripts/**`, `docs/grillmax/**`.
            Продуктовый код не трогать. Если при проверке найдётся, что портрет **уже** утекает ПДн — не чинить молча: остановись и сообщи оркестратору (это продуктовый вопрос, а не правка теста).
ПРОВЕРКА  : (из корня рабочего каталога задачи — worktree)
            `PYTHONPATH=src /opt/dashboard/venv-lunora/bin/python -m pytest -q tests/test_llm_portrait_privacy.py` — зелёный выход.
            `PYTHONPATH=src /opt/dashboard/venv-lunora/bin/python -m ruff check tests/test_llm_portrait_privacy.py` — зелёный выход.
КРИТЕРИЙ  : (а) тест собирает пакет портрета из карты с ПДн-полями (ФИО, дата рождения, место рождения/город, `user_id`, Telegram id) и доказывает, что в пакете их нет; (б) тест не пустой: пакет портрета содержит ожидаемое содержимое (тексты планет, число жизненного пути); (в) «красным»: подложенная ПДн, дошедшая до пакета портрета, роняет набор — мутация зафиксирована в agent-log.
СКИЛЛ     : python, pytest — стандартная библиотека.
РЕВЬЮ     : Слепой ревьюер: «путь портрета действительно покрыт, тест не пустой». Безопасник — отдельный проход: «в фикстурах нет реальных ПДн». Критик ревью — обязателен.
