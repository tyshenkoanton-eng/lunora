# S3b-01 · Приватность пакета, уходящего в модель (152-ФЗ)

TASK      : Сделать проверяемым требование «в пакете, который уходит в модель, нет персональных данных». Две части: (1) вынести сборку пакета из `src/lunora/llm/client.py` в чистую функцию `build_messages(...)` без изменения поведения; (2) добавить тест, который краснеет, если в пакет попали имя, дата или место рождения, город, `user_id` или Telegram id.
ВХОД      : `src/lunora/llm/client.py` (сборка `system` / `user_content` / `history`), `src/lunora/llm/prompts.py` (`SYSTEM_PROMPT`, аддендумы безопасности, `format_chart_data`), `src/lunora/api/routes.py` (как `chart_data` собирается из строки БД), требование приватности — `docs/current/G17-S1-план.md` § «Приватность (152-ФЗ)».
ГРАНИЦЫ   : Запись — `src/lunora/llm/client.py`, новый `tests/test_llm_privacy.py`, `docs/current/agent-log/S3b-01.md`. Всё остальное — read-only. **Нельзя:** менять тексты промптов, формат карты, схему БД, `docs/grillmax/**`, `docs/current/ROADMAP_STATUS.yaml`, `src/lunora/llm/prompts.py`.
            **Граница продукта:** текст вопроса пользователя и история диалога — его собственные слова; фильтровать или переписывать их нельзя. Приватность проверяется на данных карты и служебных полях. Любая правка поведения ответа — за оператором.
ПРОВЕРКА  : (из корня рабочего каталога задачи — worktree) `PYTHONPATH=src /opt/dashboard/venv-lunora/bin/python -m pytest -q tests/test_llm_privacy.py` — зелёный выход.
            `PYTHONPATH=src /opt/dashboard/venv-lunora/bin/python -m ruff check src/lunora/llm/client.py tests/test_llm_privacy.py` — зелёный выход.
КРИТЕРИЙ  : (а) `build_messages` — чистая функция без сети; результат совпадает с прежней сборкой побайтово (golden-фикстура на точное ожидаемое сообщение); (б) тест краснеет, если в исходную карту или служебные поля подложены ФИО, дата рождения, место рождения/город, `user_id`, Telegram id; (в) тест зелен на карте, где есть только градусы, знаки, дома и текст, **и** проверяет, что в пакете реально есть планеты — пустой пакет тест не пропускает; (г) отчёт задачи содержит доказательство «красным»: какая именно мутация заставляет тест краснеть.
СКИЛЛ     : python, pytest, ruff — правила проекта в `pyproject.toml` (line-length 99, `select = ["E","F","I","UP","B","SIM"]`).
РЕВЬЮ     : Слепой ревьюер (не видит рассуждений исполнителя): «в пакете не может быть ПДн, и поведение сборки не изменилось». Безопасник — отдельный проход: «в тесте нет ключей, токенов и реальных ПДн; в коммит не попало ничего секретного». Критик ревью — обязателен: отсекает ложные претензии.
