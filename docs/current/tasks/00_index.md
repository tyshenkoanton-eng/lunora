Форма задачи — [../../TASK_CONTRACT.md](../../TASK_CONTRACT.md). Контур исполнения — [../../EXECUTION_PROTOCOL.md](../../EXECUTION_PROTOCOL.md). Ревью — [../../REVIEWER_CHARTER.md](../../REVIEWER_CHARTER.md).
