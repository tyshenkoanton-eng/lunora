S3b-13…S3b-17 — следователи по находкам второй волны (слепое ревью + критика). Их потребитель —
**блокеры закрытия гейта**: пока они не сделаны, зелёный гейт не означает «приватность и дрейф
порогов защищены автоматически».

Контракты S3b-05…S3b-07 (отчёт, пересчёт R-05, close-record) не написаны: их вход — живой замер,
а он ждёт ключа оператора; форма пересчёта R-05 уже зафиксирована в карточке гейта.
Разбивка целиком — в карточке гейта [../G17-S3b-план.md](../G17-S3b-план.md).
