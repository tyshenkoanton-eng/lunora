# `docs/current/` — живая часть проекта

Папка текущего состояния: что делается сейчас, что закрыто и что ждёт решения.
Источник правды по статусу — [ROADMAP_STATUS.yaml](ROADMAP_STATUS.yaml); витрина `../../ROADMAP_BOARD.md`
генерируется из него (`scripts/board_gen.py` → `make board`).

| Что | Где |
|---|---|
| Статус карты L→G→S→R | [ROADMAP_STATUS.yaml](ROADMAP_STATUS.yaml) — правится руками, он источник |
| Журнал слайса, append-only | [WORKLOG.md](WORKLOG.md) |
| Карточки гейтов и планы | [G17-S1-план.md](G17-S1-план.md) · [G17-S2-план.md](G17-S2-план.md) · [G17-S2f-план.md](G17-S2f-план.md) · [G17-S3-план.md](G17-S3-план.md) · [G17-S3b-план.md](G17-S3b-план.md) |
| Контракты атомарных задач | [tasks/](tasks/00_index.md) |
| Артефакты спайков (протоколы, отчёты) | [spike/](spike/00_index.md) |
| Живой след агентов | `agent-log/` (по файлу на задачу) · `events.jsonl` (поток событий) |

Правила: документ живёт, пока у него есть названный потребитель. Один дом на факт:
статус — в `ROADMAP_STATUS.yaml`, всё остальное ссылается на него, а не пересказывает.
