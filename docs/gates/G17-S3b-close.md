## Что сделано

- **Живой замер** `scripts/spike/llm_measure.py` через OpenRouter: 5 моделей × 3 сценария
  (вопрос в чате / портрет-документ / утренний прогноз) × 5 синтетических карт A–E («Тест»,
  без ПДн — к моделям уходят только градусы+текст, 152-ФЗ). Себестоимость = фактический
  `usage.cost` OpenRouter × курс 79 ₽/$ × наценка ×1,0.
- **Артефакт** `docs/current/spike/llm_cost.json` расширен до **маршрутизации задача→модель**:
  каждый сценарий несёт свою модель и цены (чат=Sonnet 5.5, документ=Opus 5.5, прогноз=Haiku 5.5).
  Схема `llm_cost.schema.json` и чекер `llm_cost.py` обновлены (per-scenario `model`+`pricing`);
  сырьё — `llm_compare.json` (все 5 моделей, образцы ответов для слепой оценки качества).
- **Голос промптов исправлен** (обратная связь оператора на своей карте): `prompts.py` и
  `interpret/portrait.py` — обращение строго на «вы», нейтрально по роду (пол в LLM не уходит,
  152-ФЗ), только русский без латиницы. Якоря в `test_llm_privacy.py` обновлены осознанно.

## Находки

1. **Opus 5.5 для чата — вне бюджета** (4,73 ₽/вопрос > 3,01): у Claude 5.5 «мышление»
   нельзя выключить (Opus/Sonnet → HTTP 400 на `reasoning.enabled=false`; только Haiku можно),
   и оно тарифицируется как выход. Качество Opus и Sonnet в слепом тесте на карте оператора —
   сопоставимо → **чат на Sonnet 5.5** (вдвое дешевле, в пороге).
2. **Боевой `client.py` багует на Claude 5.5:** `max_tokens=1000` без управления ризонингом
   → `finish_reason=length`, `content=None` (пустой ответ, токены тарифицируются). Рабочий
   конфиг замера: `reasoning:{effort:"low"}` + `max_tokens=3000`. **Хвост — отдельной задачей
   слоя llm** (не scope S3b).
3. **Наценка посредника ≈ ×1,0** (не ×1,5): OpenRouter отдаёт фактический `usage.cost`. Вместе
   с курсом 83,59→79 и подешевевшим Claude — все поправки бюджета ВНИЗ (см. разбор бюджета).
4. **Прогноз измерен пессимистично** (через чат-харнесс, выход ~1150 ток.); реальный лёгкий
   промпт прогноза дешевле. Даже так Haiku в пороге (0,54 ≤ 1 ₽/мес). Точную цифру снять на
   боевом `forecast/generate` при доводке продукта.
5. **Будущий «тяжёлый документ» §3.1** (вход ~4к / выход ~15к, в коде ещё НЕТ): проекция на
   Opus ≈ 25 ₽ > порога документа 10 ₽ (вариант A). Для таких — дешёвая модель или отдельный
   порог; снять, когда появится сам продукт.
6. **Живой баг портрета** (хвост S2e): западные планеты не попадают в сборку блоков (рус.
   имена в карте vs англ. ключи `interpret/planets.py`). Для замера наведён мост рус→англ в
   харнессе (мерили задуманный ~720-ток. вход, не вырожденный). **Чинить в слое интерпретации
   (S3/S4)**, не в S3b.

## Микрорешения

- Артефакт сделан per-scenario-model (а не одной моделью): продукт реально маршрутизирует
  задачу на свою модель, и дрейф-гард S3b-04 должен проверять именно это. Это завершение
  задачи S3b-04, не раздувание scope.
- Бэкап-вендор — **GPT-5.6** (через тот же OpenRouter, OpenAI-совместимый endpoint; смена =
  1 строка конфига). Отечественные (YandexGPT/GigaChat/T-pro) — отдельный трек на будущее
  (нет в OpenRouter, 152-ФЗ-плюс), не для этого замера.
- Образцы ответов в `llm_compare.json` сняты ДО фикса голоса (cost-замер стартовал раньше);
  себестоимость от голоса не зависит, голос проверен отдельно на карте оператора.

## Хвосты, заведённые наружу S3b (в S3/S4)
