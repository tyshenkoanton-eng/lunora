# Close-record G17-S2e — переключение рантайма на движки (точка P3 закрыта)

**Дата:** 2026-11-22 · **Слайс:** G17-S2e (переключение рантайма; закрывает точку P3) ·
**Вердикт:** PASS
**Критерий:** зелёные `make verify` (757 passed, 18 skipped) и `make slice-check`
(накопительно S1 + S2a + S2c + S2b + S2d + S2e). Карточка —
[../current/G17-S2-план.md](../current/G17-S2-план.md).

Этот слайс выделен из S2d по заранее одобренному решению Антона №4: он меняет контракт
API, форму хранимого чарта, слой интерпретации и бота — это интеграция, а не ещё один движок.
**С его закрытием точка P3 гейта G17 закрыта окончательно:** все четыре движка построены и
доказаны на golden против внешних эталонов (S2a–S2d), рантайм переведён на них, AGPL-оракулы
и тяжёлые пакеты выведены из рантайма.

## Что сделано

- **`calc.engine` на `lunora.engines.*`.** `calculate(BirthData)` теперь: `BirthData` →
  `ResolvedMoment` (`timeplace.resolve`, доказан в S1) → четыре движка (`western`, `vedic`,
  `bazi`, `numerology`) поверх `_ephem` (Skyfield + DE440s) → контракт `calc.types`. Прежние
  прототипные `calc/{western,vedic,chinese,numerology}.py` (на `swisseph`/`cnlunar`) снесены.
- **Форма хранимого чарта сохранена** (`calc.types`): потребители `api/routes`,
  `calc/serialize`, `llm/prompts`, `interpret/portrait` и `test_serialize` не трогались —
  движки маппятся в те же dataclass'ы. Ведические грахи отдаются санскритом (`Сурья`,
  `Чандра`, `Мангала`…) — engine-native, аутентично для джйотиша.
- **`test_calc.py` переписан** на новый слой (не отключён — канон). Эталон
  15.03.1990 14:30 Москва; значения сверены с golden S2a–S2d: Солнце 24°62′ Рыбы, Луна
  Скорпион, ASC Лев, 12 планет / 12 домов / 16 аспектов; айанамша 23,72°, накшатра Чандры
  Свати пада 3 (владыка Раху), 9 МД Вимшоттари (Раху→…, сумма 120 лет); год 庚午 (Лошадь),
  господин дня 己 (Земля/Инь); число пути 1, число дня 6, квадрат (три единицы).
- **`calc/timezone.py` без `timezonefinder`.** `timezone_for` → ближайший город
  вендоренного снимка GeoNames `cities15000` (data/vendor/geonames, манифест + SHA-256),
  равнопромежуточная метрика с поправкой cos φ, без сети. Единственный потребитель — UX
  `/geocode`.
- **Оракулы вне рантайма (ADR-001).** `pyswisseph`, `cnlunar`, `timezonefinder` убраны из
  `[project.dependencies]`. `cnlunar` перенесён в `[oracle]` (оракул дифф-теста Ба-Цзы),
  `timezonefinder` снят совсем. `tests/test_runtime_no_oracles.py` — статический (AST) запрет
  импорта `{swisseph, jhora, pyjhora, cnlunar, lunar_python, timezonefinder}` для всего
  `src/lunora`; падает, если рантайм потянет оракул.
- **`make slice-check-s2e`** — интеграционная проверка слайса (сборка на движках, зоны на
  GeoNames, запреты импорта), заведена в накопительный `make slice-check`.

## Точка P3 — закрыта

Содержательный критерий P3 («корректность ядра: четыре системы считаются верно, из одного
доказанного ядра, без AGPL-оракулов в рантайме») выполнен: движки доказаны (S2a–S2d),
`calc.engine`/бот/API работают на них, оракулы только в `[oracle]`/`tests/diff`. Эфемеридный
и время-поясной слой закрыты в S1. Гейт G17 по корректности ядра — закрыт.

## Границы (held, S4 / out_of_v1)

Баллы Лилли, йоги, скрытые стволы, баланс стихий §5.7 со скрытыми стволами, сила господина
дня, «квадрат после 2000» (fail closed), полный продуктовый справочник мест — вне S2
(`out_of_v1`/`known_gap`). Длина года даш (Y=365,25 vs true sidereal solar year) — развилка
§4.3, решается при переносе дат даши в продукт.
