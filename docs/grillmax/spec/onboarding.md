# Блок: Онбординг

**Статус:** ✅ согласован · **Экраны:** О-01…О-07 (obStart…obRun), В-01 (welcome), Б-01/Б-02 (бот), Ф-03, Ф-08/Ф-09/Ф-10/Ф-12 (подсказки); показ П-01…04 — см. `spec/profile.md`
**Связанные доки:** `onboarding-flow.md`, `depth-model.md` (глубина и точность времени), `agreement-rules.md` (согласие).

Путь от первого касания до готового разбора. Самый хрупкий участок: онбординг стоит **перед** ценностью — эти экраны просят и ничего не дают, поэтому каждый решает **одну задачу** и объясняет, зачем спрашивает.

---

## Вход

| Код | Экран | Назначение |
|---|---|---|
| `О-01` obStart | Карточка бота до запуска | одно нажатие «ЗАПУСТИТЬ»; имя, @-адрес, **видео-автоплей** результата, одна строка описания |
| `Б-01` | Первое сообщение бота | приветствие, что сделаем и в чём отличие, что понадобится, кнопка «Построить карту» → Mini App |
| `В-01` welcome | Приглашение · страница по ссылке | лендинг для пришедших по реферальной ссылке |
| `Б-02` | Бот · вход по приглашению | ветка бота для приглашённого |

⚠️ **«ЗАПУСТИТЬ» обязательно.** Без запуска бот не имеет права присылать сообщения (ежедневный прогноз, возврат, доставка документов). Открыть Mini App в обход бота нельзя (`safety-rules.md`).

## Шаги формы (О-02…О-07)

### О-02 · Знакомство (`obName`) — Шаг 1
Индикатор четырёх шагов · «Как к вам обращаться?» · поле имени · **выбор пола** · «Дальше».

⚠️ **Пол обязателен для расчёта** (ведическая и Ба-Цзы), не для текста — потому спрашивается здесь. **Ничего не предвыбрано:** пол не угадывается по имени, безопасного умолчания нет. Одно поле имени (оно же в нумерологию). Просьба свериться с документами — не здесь, а при дополнении ФИО в настройках.

Подсказки (шторка infoSheet): `Ф-08` зачем полное имя, `Ф-09` зачем пол, `Ф-12` глубина расчёта.

### О-03 · Место рождения (`obPlace`) — Шаг 2
«Где вы родились?» · поле города с подсказками · **полоса глубины** · «Дальше».

| Состояние | |
|---|---|
| Город не выбран | глубина 0%, блок адреса скрыт |
| Город выбран | глубина оживает, появляется «Уточнить адрес» |
| Город не найден | ручной ввод координат / ближайший крупный город (открытый вопрос) |

🔑 Блок адреса не показывается, пока не выбран город (изменения идут вниз по экрану). 🔑 Полоса глубины появляется здесь и живёт до конца онбординга.

### О-04 · Дата рождения (`obDate`) — Шаг 3 (самый тяжёлый)
День/месяц/год · время · **четыре сегмента точности** · глубина · «Дальше».

| Сегмент | Как человек знает | Код |
|---|---|---|
| Точно | смотрел в документах (±5 мин) | `О-04-1` |
| **± 30 мин** | «около двух» — **предвыбрано** | `О-04-2` |
| ± 3 часа | «под утро» → блок частей суток | `О-04-3` |
| Не знаю | считаем без времени | `О-04-4` |

⚠️ **Сегменты над полем**, не под ним (при смене меняется то, что ниже касания). ⚠️ **«± 30 мин» предвыбрано** — предвыбор ошибается в безопасную сторону (заниженная точность лучше завышенной). Без времени теряется ~треть разбора (дома, восходящий, столп часа) — массовый случай. Подсказка `Ф-10` — важность времени. Этот же паттерн точности переиспользован в Личных данных (см. `spec/personal-data-recalc.md`).

### Ф-03 · Шторка выбор значения (`pickSheet`)
Ключ `obDate`, `sheet=pickSheet`. Колесо выбора значения (день/месяц/год/час) на экране даты.

### О-05 · Согласие (`obConsent`) — Шаг 4
Объяснение зачем · строка про удаление по требованию · **галочка** · строка о старте расчёта · глубина · «Начать расчёт».

🔑 Ссылкой подсвечена сама формулировка согласия (видно, на что нажимаешь). ⚠️ Согласие — **отдельный документ**, не часть оферты (156-ФЗ). Оферта акцептуется оплатой — здесь принимать не нужно. Кнопка неактивна до галочки, ничего не предотмечено.

### О-06 · Проверьте данные (`obCalc`)
Имя · дата и время с допуском · место · ссылка «изменить». Варианты `О-06-1/2` (полные/неполные данные).

🔑 **Подтверждение без отдельного шага** — встроено в экран расчёта, не выделено в пятый шаг. ⚠️ Правка здесь **не считается в лимит правок** (человек ещё ничего не получил).

### О-07 · Расчёт (`obRun`)
Прогресс по школам с осмысленными подписями («Считаем, где стояли планеты …»). 🔑 Расчёт как шоу — конкретная дата и действие, не «загрузка».

| Состояние | |
|---|---|
| Дольше 15 секунд | «Считаем дольше обычного», не бросать |
| Ошибка движка | «Попробуем ещё раз» + автоповтор |

Этот же приём видимого ожидания переиспользован при пересчёте (Л-23, `spec/personal-data-recalc.md`).

## Выход

После расчёта — **показ** (П-01…04, четыре слайда первого знакомства) → профиль. Показ описан в `spec/profile.md`. 🔑 Показ существует один раз, вернуться к нему нельзя.

## Открытые вопросы

- Плашка «тебя пригласила Анна» для пришедших по реферальной ссылке — не отрисована.
- Состояния при потере сети на середине формы; что сохраняется при закрытии приложения.
- Экран для города, которого нет в базе.
