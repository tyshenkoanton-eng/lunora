# Блок: Профиль и показ

**Статус:** ✅ согласован · **Экраны:** Л-01 (profile), Ф-01, П-01…П-04 (показ)
**Связанные доки:** `depth-model.md` (глубина), `referral-model.md` (пилюля приглашения), `consensus-map.md`.

Профиль — дом пользователя: кто он по картам и куда идти дальше. Показ — первое знакомство сразу после расчёта карты, он ведёт в профиль.

---

## Л-01 · Профиль (`profile`)

**Назначение.** Главный бесплатный экран: сводка по человеку, вход в темы, школы и периоды.

**Состав.**

| Блок | |
|---|---|
| Шапка | Имя · **пилюля «Пригласить»** (с точкой при непогашенном бонусе) · шестерёнка настроек |
| Строка данных | ФИО, дата, время, город |
| **Глубина разбора** | Полоса с процентом, раскрывается в разбивку (что есть ✓ / что добавит сколько %) |
| Ориентирующая карточка | Закрываемая навсегда: что такое темы и что такое школы |
| Переключатель | **Темы / Школы** (вкладки) |
| Темы | Список тем, название + одна фраза → экран темы |
| Школы | Четыре школы, название + состав → разбор по школе (Л-09…12) |
| Периоды жизни | Шкала вимшоттари-даши с текущим положением |
| Поделиться | |

**Состояния (каталог).** Вкладки × состояние PDF:

| Код | Вкладка | Состояние PDF |
|---|---|---|
| `Л-01а-1/2/3` | Темы | не куплен / куплен / данные изменились |
| `Л-01б-1/2/3` | Школы | не куплен / куплен / данные изменились |

«Данные изменились» (stale) — после пересчёта купленный PDF помечается как требующий пересборки (связь с блоком «Личные данные → пересчёт» и `idempotency.md`).

**Элементы и поведение.**

| Элемент | Поведение |
|---|---|
| Пилюля «Пригласить» | → экран рефералов (Н-03). Точка — только при неполученном бонусе (`referral-model.md`). |
| Шестерёнка | → Настройки (Н-01). |
| Полоса глубины | Тап раскрывает разбивку (закрыта по умолчанию). Раскрытие — что уже есть и что добавит сколько процентов (`depth-model.md`). |
| Вкладки Темы/Школы | Переключают список; вкладка входит в адрес (Л-01а/б). |
| Карточка темы/школы | → экран темы / разбор по школе. |
| «Как устроен разбор» | Открывает шторку Ф-01. |

**Состояния общие.** Пустого нет (профиль строится из карты, посчитанной при регистрации). Частичные данные — глубина ниже 100%, в разбивке видно, чего не хватает. Загрузка — скелетон (строки тем полосами).

**Правила.** Периоды — настоящие даши, не выдуманные отрезки. Ориентирующая карточка закрывается навсегда. Пилюля показывает точку только при неполученном бонусе.

### Ф-01 · Шторка «как устроен разбор»
Ключ `profile`, `sheet=introSheet`. Поясняет устройство разбора (темы vs школы, что бесплатно). Вызывается с профиля.

## Показ · П-01…П-04 (`s1`…`s4`)

**Назначение.** Первое знакомство сразу после расчёта карты: четыре сильных утверждения о человеке. Запускается в конце онбординга (после О-07 «Расчёт»), ведёт в профиль.

**Состав слайда.** Содержательный блок по центру · строка навигации внизу.

**Навигация.**

| Слайд | Строка внизу |
|---|---|
| 1 | стрелка назад неактивна · точки · стрелка вперёд |
| 2–3 | назад · точки · вперёд |
| **4** | назад · **кнопка «Познакомиться с собой»** во всю ширину → профиль |

🔑 **На последнем слайде точки убираются** (осталось ноль, место отдаётся кнопке). **Кнопка занимает позицию правой стрелки** — палец продолжает то же движение и попадает в продукт. Ведёт в профиль; действие не разрушительное, назад доступно.

⚠️ **«Последний слайд» зашит числом (4).** Если между показом и профилем встанет ещё экран, кнопку на позиции стрелки придётся пересматривать.

**Правила.** Активная точка отличается цветом, не размером (растягивание сдвигало соседние).
