# Блок: Профиль и показ

**Статус:** ✅ согласован · **Экраны:** Л-01 (profile), Ф-01, П-01…П-04 (показ)
**Связанные доки:** `depth-model.md` (глубина), `referral-model.md` (пилюля приглашения), `consensus-map.md`.

Профиль — дом пользователя: кто он по картам и куда идти дальше. Показ — первое знакомство сразу после расчёта карты, он ведёт в профиль.

---

## Л-01 · Профиль (`profile`)

**Назначение.** Главный бесплатный экран: кто человек по картам, вход в темы и школы.

**Состав (текущий прототип).**

| Блок | |
|---|---|
| Шапка | аватар (из Telegram) · имя и фамилия (мельче прежнего) · **шестерёнка настроек** у правого края. Ниже — линия-разделитель, отделяющая верх шапки от карусели. Приглашение в шапке не живёт (ушло в футер) |
| **Карусель утверждений** | `PCLAIMS` — несколько сильных утверждений о человеке, листаются вбок, с точками-индикаторами |
| «Подробно о вас» | строка объёма разбора (`scopeLine` — сколько тем/школ посчитано) |
| Переключатель | **Темы / Школы** (вкладки `pvTabs`) |
| Темы | список тем (название + одна фраза) → экран темы |
| Школы | четыре разбора по школам → Л-09…12 + ориентирующий блок «у каждой школы свой взгляд» (чем сильна западная/ведическая/Ба-Цзы/нумерология) |
| Футер | кнопка PDF (по состоянию) · «Поделиться картой» · **«Пригласить друга»** |

**Элементы и поведение.**

| Элемент | Поведение |
|---|---|
| Шестерёнка | → Настройки (Н-01). Прижата к правому краю шапки. |
| Карусель `PCLAIMS` (`data-pcd`) | Листается вбок; точки показывают позицию. |
| Вкладки Темы/Школы (`data-pv`) | Переключают список; вкладка входит в адрес (Л-01а/б). |
| Карточка темы | → экран темы (`spec/themes.md`). |
| Карточка школы | → разбор по школе (dWest…dNum). |
| Кнопка PDF (футер) | Зависит от состояния PDF (`PDFST`): не куплен → «Скачать PDF» (→ pdfSell); **stale** → «Обновить PDF — бесплатно» (→ docBuild); куплен → кнопки нет. |
| «Поделиться картой» | Системный лист отправки. |
| «Пригласить друга» (футер, `data-go=invite`) | Ghost-кнопка в группе действий внизу, рядом с «Поделиться картой» (соседи по смыслу — оба про «поделиться»): иконка-подарок + подпись → экран приглашений (Н-03). Точка-уведомление (`INV_EVENT`, как у непрочитанных) при событиях рефералки, гаснет при открытии. Основной вход в рефералку (`spec/referral-model.md`). Вынесена в футер, чтобы промо не теснилось к имени в шапке. |

**Состояния (каталог).** Вкладка × состояние PDF (`PDFST`):

| Код | Вкладка | PDF |
|---|---|---|
| `Л-01а-1/2/3` | Темы | не куплен / куплен / данные изменились (stale) |
| `Л-01б-1/2/3` | Школы | не куплен / куплен / данные изменились (stale) |

**stale** — после пересчёта купленный PDF помечается требующим бесплатной пересборки (связь с блоком «Личные данные → пересчёт» и `idempotency.md`).

**Состояния общие.** Пустого нет (профиль строится из карты, посчитанной при регистрации). Загрузка — скелетон.

> 🔑 **Профиль — как в текущем прототипе (решение Антона).** Полоса глубины на профиль не возвращается (живёт в Настройках, плашка в разделе «Данные», `spec/settings.md`); периоды жизни — это темы «Периоды» Л-20 и «Кризисы» Л-21, отдельного блока в профиле нет.
>
> 🔄 **Вход в рефералку — в футере профиля (решение Антона).** Основной вход — кнопка «Пригласить друга» в группе действий внизу, рядом с «Поделиться картой»; вторичный — строка в Настройках. Пробовали таблетку в шапке (рядом с именем и настройками) — ощущалась как промо в зоне идентичности, поэтому вынесли в футер. Из полосы чата приглашение тоже убрано (осталась альтернатива на пейволе Ч-03 и карточка в «Разговоре» Р-02). Детали — `spec/referral-model.md`.

### Ф-01 · Шторка «как устроен разбор»
Ключ `profile`, `sheet=introSheet`. Поясняет устройство разбора (темы vs школы, что бесплатно). Вызывается с профиля.

## Показ · П-01…П-04 (`s1`…`s4`)

**Назначение.** Первое знакомство сразу после расчёта карты: четыре сильных утверждения о человеке. Запускается в конце онбординга (после О-07 «Расчёт»), ведёт в профиль.

**Состав слайда.** Содержательный блок по центру · строка навигации внизу.

**Навигация.**

| Слайд | Строка внизу |
|---|---|
| 1 | стрелка назад неактивна · точки · стрелка вперёд |
| 2–3 | назад · точки · вперёд |
| **4** | назад · **кнопка «Познакомиться с собой»** во всю ширину → профиль |

🔑 **На последнем слайде точки убираются** (осталось ноль, место отдаётся кнопке). **Кнопка занимает позицию правой стрелки** — палец продолжает то же движение и попадает в продукт. Ведёт в профиль; действие не разрушительное, назад доступно.

⚠️ **«Последний слайд» зашит числом (4).** Если между показом и профилем встанет ещё экран, кнопку на позиции стрелки придётся пересматривать.

**Правила.** Активная точка отличается цветом, не размером (растягивание сдвигало соседние).
