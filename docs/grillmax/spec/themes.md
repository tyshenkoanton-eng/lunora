# Блок: Темы

**Статус:** ✅ согласован · **Глубина:** полная · **Экраны:** Л-02, Л-03, Л-04, Л-05, Л-06, Л-07, Л-08, Л-19, Л-20, Л-21, Л-22, Ф-05
**Связанные доки:** `consensus-map.md` (согласие школ, паттерны), `skeletons.md` (скелеты), `content-structure.md` (тон), `engine-spec.md` (генерация текстов).

Темы — это ответы на человеческие вопросы («какой у меня характер», «что с деньгами»), собранные из всех четырёх школ сразу. В отличие от экранов школ (одна система, свой чертёж), тема сводит четыре школы по одному вопросу и даёт итог словами Луноры.

⚠️ **Тексты тем — заглушки.** Опоры настоящие (положения планет, столпы, числа), сами трактовки пишутся движком к G10.

## Экран темы (общий, `themeScreen`)

**Назначение.** Ответ на один жизненный вопрос, сведённый из четырёх школ.

**Состав (текущий прототип).**
1. Назад → профиль; заголовок темы.
2. **«Трактовка Луноры»** (`luna-block`): ведущая фраза + подсекции (заголовки из `TH1[k]` — напр. «Как вы устроены» — и «Что мешает») + при расхождении школ подсекция **«Где школы расходятся»** (`d.diverge`).
3. Разделитель **«Источники»**.
4. **Школы карточками** (`schBlock`) в порядке `schOrder(k)`: название школы · (для темы «Периоды» — лента времени) · опора и короткий текст · ссылка **«Прочитать подробно ›»** на разбор элемента этой школы · при необходимости «Как это посчитано».
5. **Молчащие школы** (`schSilent`) показываются отдельной карточкой: «молчит — в этой системе нет инструмента для расчёта такой темы».
6. Блок телесных соответствий (`bodyZone`) — **выключен решением продукта** (`BODYZONE_ON = false`).
7. При наличии — **«Что с этим делать»** (`luna-block todo-block`): список действий.
8. **«Поделиться разбором»** (`data-share`, → системный лист Ф-05).
9. Блок **«Остались вопросы?»** → чат («Лунора отвечает, опираясь на вашу карту»).
10. **«Следующая тема»** (`nextsec`) → следующая тема по `TORDER`; на последней — «Вернуться в профиль».

| Элемент | Поведение |
|---|---|
| Карточка школы | Опора этой школы по теме (положение/столп/число) + короткое пояснение. |
| «Прочитать подробно ›» | → разбор элемента школы (`spec/schools.md`), с проставленной темой (`data-tset`). |
| Молчащая школа | Явно сказано, что у системы нет инструмента для темы — блок не скрывается. |
| «Поделиться разбором» | Системный лист отправки (Ф-05). |
| «Перейти в чат» | → чат (Ч-01). |
| «Следующая тема» | Последовательный переход по `TORDER`; последняя → профиль. |

🔑 **Расхождение подаётся как содержание, а не дефект.** Если школы расходятся — это отдельная подсекция «Где школы расходятся», а не предупреждение об ошибке. Пример (Семья и род): нумерология даёт максимум привязанности, ведическая — потребность в дистанции. Обе правы одновременно. Молчание школы по теме — тоже честный факт, а не пропуск.

⚠️ **Сводного числа по теме не бывает.** Меры школ несопоставимы, поэтому итог даёт Лунора словами, а не процентом/баллом. Шкалы характеристик были удалены именно поэтому — не возвращать.

**Состояния.** Пустого состояния нет (тема строится из карты, посчитанной при регистрации). Частичные данные — затронутые опоры помечены, не скрыты. Загрузка — скелетон.

### Ф-05 · Системный лист · поделиться
Ключ `tCharacter`, `sheet=osShare`. Нативный лист отправки (поделиться ссылкой/файлом). Общий механизм шеринга, вызывается с экрана темы (`data-share`).

## Согласие школ — где оно показывается

Явный индикатор «Все школы согласны» с точками по каждой школе (`agree`) живёт **в показе** (слайды П-01…П-04, `spec/profile.md`), не на экране темы. На экране темы согласие выражено содержанием: подсекция «Где школы расходятся» и молчащие школы. Логика согласия — `consensus-map.md`.

## Связи

- **«Отношения и любовь» (Л-19, tLove)** — это тема (четыре школы про любовь/отношения самого человека). Не путать с разделом «Люди»: `peopleRel` (Л-13) и `compat` (Л-15) — отдельный блок про других людей (`spec/people.md`).
- **«Периоды жизни» (Л-20, tPeriod)** и **«Кризисы и переломы» (Л-21, tCrisis)** — темы на основе периодов (даши, десятилетия, профекции); расчёт периодов — в блоке «Школы» (`spec/schools.md`).
- Школьные карточки темы ведут в разборы элементов (`spec/schools.md`); чат — `spec/chat.md`.

## Открытые вопросы

- Тексты всех тем — заглушки (G10), генерируются движком (`engine-spec.md`) по скелетам и карте согласия.
- Блок телесных соответствий (`bodyZone`) выключен решением продукта — вернуть или удалить окончательно не решено.
