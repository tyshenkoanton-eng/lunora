# Блок: Состояния и крайние случаи

**Статус:** ✅ согласован · **Экраны:** Х-02 (states), Х-05 (stPartial), Х-06 (stTime), Х-07 (stLat); платёжные сбои Х-01/Х-03/Х-04 — см. `spec/payment.md`
**Связанные доки:** `07_mockups.md` §5 (режимы экранов).

Общие режимы отображения и нетипичные ситуации с данными/картой.

---

## Пять режимов экрана

Применяются к любому экрану (демо-экран — `Х-02` states).

| Режим | Ключевое |
|---|---|
| Норма | обычный вид |
| Загрузка | **скелетон по форме экрана**, не спиннер |
| Пусто | **только 5 экранов**: «Сегодня», чат, мои разборы, люди, документ до оплаты. Остальное строится из карты, посчитанной при регистрации, — пустым быть не может |
| Ошибка | **четыре текста** по тому, чей сбой: банк, наш расчёт, текст раздела, сервер |
| Офлайн | полоса сверху, экран остаётся читаемым |

---

## Крайние случаи с данными

| Код | Ситуация | Поведение |
|---|---|---|
| `Х-05` stPartial | Неполные данные | затронутые блоки помечены (чего не хватает и что добавит), не скрыты; ведёт на уточнение (Л-16) |
| `Х-06` stTime | Время неизвестно | дома, восходящий, столп часа не считаются; разделы помечены; глубина ниже (`depth-model.md`) |
| `Х-07` stLat | Высокие широты | дома/некоторые расчёты вырождаются у полярных широт — обрабатывается отдельно |

## Платёжные сбои

Платёж без подтверждения (`Х-03` stWebhook), двойная оплата (`Х-04` stDouble), отказ банка (`Х-01` payFail) — вне общей схемы состояний, описаны в `spec/payment.md`. Принцип: деньги в безопасности (холд), статус проверяется, возврат до обращения.
