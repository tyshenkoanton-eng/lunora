# Блок: Сегодня

**Статус:** ✅ согласован · **Экраны:** С-01 (today), С-02 (monthPick), С-03 (slot)
**Смежное:** ежедневный прогноз — `daily-forecast.md` (С-04 настраивает доставку, контент живёт здесь).

«Сегодня» — ежедневный разбор дня по карте человека плюс дни добавленных близких. Это тот контент, который (если доставка включена) приходит сообщением бота, но доступен тут всегда, независимо от настроек доставки.

---

## С-01 · Сегодня (`today`)

**Назначение.** День пользователя по его карте + дни добавленных людей + история.

**Состав (текущий прототип).**
- **Шапка месяца** («Август 2026», `data-go=monthPick`) → С-02.
- **Полоса дней** (`daystrip`) — дни недели с отметкой текущего (`now`).
- Заголовок дня (день недели, дата) + **одна фраза** дня.
- **«Ваш день»** (luna-block) — текст прогноза + подблок **«Что стоит сделать»** (список из 2–3 пунктов).
- **«Как это посчитано»** — расчёт личного дня (нумерология: личный год → месяц → день) + ⚠️ пометка «пока считается только по нумерологии; Ба-Цзы и транзиты добавятся позже».
- **«Рядом с вами»** — карточки добавленных людей + «+ Добавить человека» + «+ Добавить третий слот».
- Нижний ряд: «Добавить человека» (→ shop) · «Спросить про день» (→ chatList). Поделиться.

| Элемент | Поведение |
|---|---|
| Шапка месяца / полоса дней | → С-02 (выбор месяца в истории). |
| «Ваш день» | Прогноз на день по карте (контент; доставка — в С-04). В прототипе считается по нумерологии (личный день), остальные школы — позже. |
| Карточка человека | День близкого; **обязан говорить, как это касается вас** («у него день разгона — учтите, что у вас противоположный»), а не быть сводкой о человеке. |
| «+ Добавить человека» | → форма Л-14 addPerson (блок «Люди»); первый близкий бесплатно. |
| «+ Добавить третий слот ›» | → продающий экран С-03. Цена не на входе — на кнопке внутри. |
| «Спросить про день» | → чат (Ч-01). |

**Состояния.** Пусто — только свой день и предложение добавить близкого (первый бесплатно).

**Правила.** Строка слота — про влияние на пользователя, не досье. Цена третьего слота — внутри, не на входе.

⚠️ **Текущий расчёт дня — только нумерология** (помечено в прототипе). В проде «Ваш день» сводит нужные школы (личный день + Ба-Цзы + транзиты).

## С-02 · Выбрать месяц (`monthPick`)
Выбор месяца для просмотра истории дней. Навигация по прошедшим дням ленты «Сегодня».

## С-03 · Третий слот (`slot`)
**Продающий экран.** Что сейчас в ленте, что добавится с третьим слотом, что покупается один раз навсегда. Цена — на финальной кнопке.

---

## Связи

- Контент дня не зависит от доставки (С-04): отключённый прогноз остаётся здесь.
- Учёт контекста (настройка памяти) влияет на содержание дня, не на его наличие.
- Добавление и удаление людей — блок «Люди» (Л-14, Н-08); слоты в «Сегодня» их отражают.
- 🔑 **Дневной слот добавленного человека считается тем же дневным движком, что и «Ваш день» — только расчёт (нумерология сейчас, позже столп дня/транзиты), а не полный разбор по школам.** Полный разбор и совместимость — платные. Решение и причины — `people.md` («что считается добавленному человеку»).
