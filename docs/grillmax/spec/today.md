# Блок: Сегодня

**Статус:** ✅ согласован · **Экраны:** С-01-1 (today · есть люди), С-01-2 (today · лента пустая), С-02 (monthPick), С-03 (slot)
**Смежное:** ежедневный прогноз — `daily-forecast.md` (Н-21 настраивает доставку, контент живёт здесь).

«Сегодня» — ежедневный разбор дня по карте человека плюс дни добавленных близких. Это тот контент, который (если доставка включена) приходит сообщением бота, но доступен тут всегда, независимо от настроек доставки.

---

## С-01 · Сегодня (`today`)

**Назначение.** День пользователя по его карте + дни добавленных людей + история.

**Состояния** (отдельные адреса в каталоге):
- **С-01-1 · есть люди** — свой день + карточка добавленного человека + пунктирный слот добавления следующего.
- **С-01-2 · лента пустая** — свой день + компактная пунктирная плашка «+ Добавить человека · первый бесплатно». «Сегодня» в пустом состоянии не подменяется общей заглушкой: свой день остаётся на экране. Подробное объяснение, что даёт добавление, вынесено на экран добавления (Л-14), чтобы «Сегодня» не нагружать приглашением на каждом заходе.

**Состав (текущий прототип).**
- **Шапка месяца** («Август 2026», `data-go=monthPick`) → С-02.
- **Полоса дней** (`daystrip`) — дни недели с отметкой текущего (`now`), горизонтальный скролл.
- Заголовок дня (день недели, дата) + **одна фраза** дня.
- **«Ваш день»** (luna-block) — текст прогноза + подблок **«Что стоит сделать»** + свёрток **«Как это посчитано»** (расчёт личного дня по нумерологии + ⚠️ пометка «пока только нумерология; Ба-Цзы и транзиты позже»). Расчёт убран внутрь блока под кнопку, отдельного блока расчёта под экраном нет.
- **«Рядом с вами»** — см. состояния ниже.
- **«Остались вопросы?»** (блок `.askchat`, яркая обводка) — текст + сплошная кнопка «Перейти в чат» (→ Ч-01).
- **«Поделиться»** — тихий футер. Отступы вокруг нижних блоков по 16px (как боковой).

**«Рядом с вами» по состояниям.**

| Состояние | Что показывает |
|---|---|
| С-01-1 (есть люди) | Карточка человека (раскрывается плюсом → крестик, как в FAQ) + пунктирный слот «+ Добавить ещё одного человека» (высотой с карточку) → С-03. |
| С-01-2 (лента пустая) | Блок-приглашение `.addintro` (пунктир): «Добавьте близкого в ленту», что это даёт, плашка «Первый человек бесплатно», кнопка «Добавить человека» → Л-14. |

| Элемент | Поведение |
|---|---|
| Шапка месяца / полоса дней | → С-02 (выбор месяца в истории). |
| «Ваш день» | Прогноз на день по карте (контент; доставка — в Н-21). В прототипе считается по нумерологии (личный день), остальные школы — позже. |
| Карточка человека | Свёрнута: имя + строка-суть (**как его день касается вас**, не досье). Раскрыта: разбор в стиле основного, но про отношение двух дней (luna-лейбл «Ваши дни рядом», фраза-суть, абзацы где совпадаете/расходитесь, список «Что учесть») + свой свёрток «Как это посчитано» (личный день близкого). |
| Пунктирный слот (есть люди) | → продающий экран С-03. Цена не на входе — на кнопке внутри. Подпись продающая, без «навсегда». |
| Блок-приглашение (пусто) | → форма Л-14 addPerson; первый близкий бесплатно (плашка). |

**Правила.** Строка карточки — про влияние на пользователя, не досье. Цена слота — внутри, не на входе. «Как это посчитано» есть и у своего дня, и у разбора добавленного человека (видимое основание).

⚠️ **Текущий расчёт дня — только нумерология** (помечено в прототипе). В проде «Ваш день» сводит нужные школы (личный день + Ба-Цзы + транзиты).

## С-02 · Выбрать месяц (`monthPick`)
Выбор месяца для просмотра истории дней. Навигация по прошедшим дням ленты «Сегодня».

## С-03 · Третий слот (`slot`)
**Продающий экран.** Что сейчас в ленте, что добавится с третьим слотом, что покупается один раз навсегда. Цена — на финальной кнопке.

---

## Связи

- Контент дня не зависит от доставки (Н-21): отключённый прогноз остаётся здесь.
- Учёт контекста (настройка памяти) влияет на содержание дня, не на его наличие.
- Добавление и удаление людей — блок «Люди» (Л-14, Н-08); слоты в «Сегодня» их отражают.
- 🔑 **Дневной слот добавленного человека считается тем же дневным движком, что и «Ваш день» — только расчёт (нумерология сейчас, позже столп дня/транзиты), а не полный разбор по школам.** Полный разбор и совместимость — платные. Решение и причины — `people.md` («что считается добавленному человеку»).
