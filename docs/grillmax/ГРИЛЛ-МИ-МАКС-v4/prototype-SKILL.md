# Prototype — кликабельный прототип под заданную фиделити

Цель: собрать кликабельный прототип, который отвечает на **один вопрос гейта**, и остановиться. Это под-скилл контура B GRILL MI MAX для двух гейтов:

- **G8, `fidelity=lo`** — серый прототип, вопрос: *понятна ли структура, проходят ли люди путь без подсказок?*
- **G10, `fidelity=hi`** — дизайн-язык применён, вопрос: *работает ли продукт как цельный визуальный опыт, читается ли копия?*

---

## Главное правило: прототип — не продукт (потолок П1)

Кликабельный прототип — **чёрная дыра**: он впитывает экраны, кейсы и копирайт бесконечно. Это главный провал v3 (310 экранов, 12 кругов ревью на wireframe). Защита:

- Прототип покрывает **Must-flows**, а не всё. Экран вне ключевого сценария — не в этой фазе.
- **Фиделити соответствует вопросу гейта.** Лоу-фай не красят (он серый by design). Хай-фай доводит до эталона **ключевые** экраны (first value + 1–2 целевых), не все.
- Итерируешь без новых **решений** — ты уже прошёл. Полировка пикселей и всех строк — это L1+, не L0.
- Прототип — **источник вида и копирайта** для разработки, но **не контракт поведения**: переходы, состояния, машины состояний живут в контрактных гейтах (G11+), прототип им не перечит, но и не заменяет.

Если чувствуешь, что «ещё чуть-чуть допилю» — это сигнал, что гейт уже пройден. Верни артефакт GRILL MI MAX.

---

## Входной контракт (что получаешь от GRILL MI MAX)

**Общее:** ICP (G3), ключевой сценарий first value (G4), карта экранов и flows (G7), список Must-flows.

**Для `fidelity=lo` (G8):** фиделити серая, визуального языка ещё нет — не раскрашивать.
**Для `fidelity=hi` (G10):** лоу-фай прототип из G8 + **дизайн-язык из G9** (токены, компоненты) + финальные тексты ключевых экранов.

Нет дизайн-языка, а просят hi → останови и верни GRILL MI MAX: «G9 не закрыт, хай-фай делать не на чем».

---

## Процесс

### Лоу-фай (G8)
1. Собери кликабельный серый прототип Must-flows: онбординг → first value → core loop → оплата/ошибки. Боксы, подписи, переходы. Без цвета, без картинок, без финальной копии (плейсхолдеры по смыслу).
2. Состояния: empty/loading/success/error по ключевым экранам.
3. **UX-тест структуры:** дай 1+ представителю аудитории конкретные задания, наблюдай где застревают. Нет доступа к тестерам → документированный solo-прогон с позиции новичка + список проблемных мест (это fallback, пометь честно).
4. Верни: прототип + протокол теста + проблемные места → в G7 на исправление структуры.

### Хай-фай (G10)
1. Примени дизайн-язык G9 к структуре из G8: токены, компоненты, типографика, тёмная/светлая.
2. Доведи **ключевые** экраны (first value + 1–2 целевых/платных) до эталона с **настоящим текстом** (не lorem) — эталонный раздел доказывает ценность копии.
3. Отрисуй пустые/error/loading визуально.
4. Приёмка визуала стейкхолдером.
5. Верни: прототип + эталонный раздел + приёмка.

## Exit-критерии (их проверяет GRILL MI MAX)

**G8 (lo):**
- [ ] Прототип покрывает ключевой сценарий (first value) и Must-flows
- [ ] Состояния (empty/loading/error/success) на ключевых экранах
- [ ] ≥1 представитель аудитории прошёл без подсказок (или честный solo-fallback с находками)
- [ ] Результаты теста задокументированы, структурные проблемы ушли в G7
- [ ] Не раскрашен, не переусложнён (потолок соблюдён)

**G10 (hi):**
- [ ] Ключевые Must-экраны в хай-фай с применённым языком G9
- [ ] Эталонный раздел с настоящим текстом (не lorem)
- [ ] Пустые/error/loading отрисованы визуально
- [ ] Приёмка визуала стейкхолдером
- [ ] Доведены ключевые экраны, а не все 300 (потолок соблюдён)
- [ ] Зафиксировано: прототип — источник вида/копирайта, не контракт поведения

## Гигиена артефакта (если прототип — один HTML-файл)
- Держи **каталог экранов** генерируемым из реестра прототипа (а не вручную) — иначе каталог отстаёт от того, что реально рендерится.
- Автоматизируй проверки: нет мёртвых переходов, нет пустых экранов рендера, нет запретных терминов в видимом тексте (по правилам продукта).
- Помечай «закрытые» экраны и сверяй их отпечаток, чтобы проверенное не менялось молча при следующей правке.

## Если инструментов нет
Браузер недоступен → статические wireframe-документы ключевых экранов + описание переходов таблицей. Передай GRILL MI MAX сигнал о деградации фиделити и невозможности живого UX-теста.
