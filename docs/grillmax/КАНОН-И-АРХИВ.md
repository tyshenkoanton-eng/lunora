# Лунора — карта документов: канон, опора, архив

**Назначение:** снять путаницу «какой документ действует». В проекте ~75 документов, но **разработкой управляет только КАНОН**. Остальное — опора (читать по ссылке) и архив (история проработки, НЕ источник истины).
**Правило:** при любом расхождении действует документ из раздела «Канон». Архив не используется как основание — только для понимания, почему принято решение.
**Дата:** 2026-11-17.

## 4. Что с этим делать

1. **Разработчик читает только Канон** (раздел 1) + Опору по ссылкам. Архив — опционально, для контекста.
2. **Физическое разделение (предложение):** переместить Архив в подпапку `archive/`, чтобы рабочий набор был чистым. Это потребует обновить ссылки канона на перемещённые файлы (напр. `RISKS.md` ссылается на `05_business.md` за цифрой себестоимости — такие ссылки правятся на `archive/…`). Делается отдельным заходом по согласованию.
3. **Правило на будущее:** новое решение идёт в Канон; устаревшая версия помечается `superseded_by` и уходит в Архив — не остаётся в активном чтении.
