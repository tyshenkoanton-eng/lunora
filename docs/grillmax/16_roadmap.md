## 2. Согласованность (П3)
- Машинная: `check-consistency.py` + `check-decision-propagation.py` — **зелёные**.
- Смысловая (вердикт агента): ключевые решения разнесены (D-121 оплата донесена во все контракты, устаревший хвост в `04_product` починен; бренд/цвет/токены согласованы; token-driven проходит сквозь G9→G11→G15). Расхождений по существу не выявлено.

## 3. Непереносимое условие — ПЕРВЫЙ L1-слайс (feasibility gate)
**До постройки фич — спайк корректности ядра (G12):**
- 4 движка (Запад/Веда/Ба-Цзы/Нумерология) прогнать на **golden-наборах**; поймать классы ошибок прототипа (пропуск Солнца, высшие планеты по знаку, год Ба-Цзы на границе — всё из `04_product`).
- Время/часовые пояса (R-52) — отдельный спайк.
- Стоимость LLM-синтеза на реальных данных vs бюджет (R-05).
- Платёжные адаптеры (Stars внутри Telegram, ЮKassa вне — D-121) — пробная интеграция.
**Если спайк показывает, что ядро нельзя сделать корректным/в бюджете → STOP/REVISE, не стройка фич поверх.**

## 4. Финальный вердикт: **GO с условиями**
Проработка достаточна, чтобы **начать реализацию**, при соблюдении условий:

**Непереносимые (блокируют соответствующий этап):**
- спайк корректности ядра (§3) — **до** постройки фич;
- юрист по 152-ФЗ / согласиям / ст.12 РКН (G13, A-08) — **до public-запуска**;
- проверка восстановления из бэкапа (G15) — **до public**.

**Переносимые (параллельно / ранний L1, под замер):**
- финальный знак бренда (G6) + финальный дизайн экранов / полировка (G10) — параллельно, впрыгивается через токены;
- **живой UX-тест с реальной аудиторией (G8)** — ранний L1, на первой когорте (solo-прогон не заменяет);
- ARPPU/конверсия (R-31/R-06), активация/retention/CAC — замер на первой когорте (G14/G15).

**STOP/REVISE, если:** спайк ядра провалился · сработал kill-criterion (G14) · принят закон № 901048-8 с фатальным эффектом (R-02).

## 5. Порядок L1 (слайсы)
1. **S1 — спайк ядра** (движки+golden, время, LLM-стоимость, платёж) — feasibility gate.
2. **S2 — токен-слой + библиотека компонентов** (ADR-003) на черновом скине.
3. **S3 — онбординг + профиль «6 шкал»** (first value) → UX-тест с людьми (G8).
4. **S4 — полный разбор + расхождение школ.**
5. **S5 — оплата (Stars) + диалог с картой** (killer, монетизация).
6. **S6 — утренний прогноз** (возврат) + аналитика событий (G14).
Дизайн-полировка и финальный знак — **параллельный трек** весь L1.
