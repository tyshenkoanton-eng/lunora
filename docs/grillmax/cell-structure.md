# Структура ячеек: что внутри каждого разбора «школа × тема»

**Дата:** 2026-09-10 · **Статус:** [РЕШЕНИЕ] · **Источник:** четыре рыночных исследования, колонка «что получает клиент»

Подзаголовки внутри разбора не придуманы нами. Они взяты из колонки, где для каждого раздела отчёта названо, что именно человек читает, и переведены на человеческий язык.

⚠️ Там, где исследование раздела не даёт, это помечено явно — и решение принимается отдельно, а не выводится по аналогии.

| Насколько вы держитесь уклада | строка 3·6·9 «стабильность» |

**Источник:** Александров, «Даты и судьбы» — строка 2·5·8 названа прямо: качество семьянина, стремление иметь семью, находиться среди близких. Плюс часть V второй книги посвящена семье целиком.

⛔ Из части V берётся только структура отношений. Возрастные соотношения супругов, потенция и женские болезни — за пределами продукта.
