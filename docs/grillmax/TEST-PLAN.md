**Дата:** 2026-08-22 · **Кому:** Антон · **Всего:** около 3,5 часов, разбитых на девять подходов
**Прототип:** [приложение, бот и касса](https://claude.ai/code/artifact/bb6f7100-1a36-4ff2-bd1e-31ff6323e738) · [макеты бота отдельно](https://claude.ai/code/artifact/d46263f0-564f-4caa-9cd1-fbbf4145234a)

## Как пользоваться планом

Идите по подходам сверху вниз. **Каждый — двадцать-тридцать минут**, дальше внимание падает и вторая половина проверяется хуже первой. Между подходами можно делать перерыв в день.

В прототипе справа есть блок **«Тестирование»**: посещённые экраны отмечаются сами, кнопка `!` рядом с адресом помечает экран с замечанием, «Замечаний: N» собирает список для копирования.

⚠️ **Первый подход невозвратный.** Второй раз вы уже будете знать продукт. Не тратьте его на вычитку подписей.

## Подход 0 · Разобраться с инструментом
**5 минут**

| Что сделать |
|---|
| Открыть прототип, найти справа блок «Тестирование» |
| Переключить режим на **① Путь** — лишние экраны приглушатся |
| Нажать на адрес экрана в шапке макета — проверить, что копируется |
| Нажать `!` рядом с адресом, потом «Замечаний: 1» — посмотреть, как выглядит сводка |
| Нажать «сбросить» |

Три кнопки над макетом — **Бот · Приложение · Оплата** — открывают первый экран каждого потока.

## Подход 1 · Путь новичка
**25 минут · режим ① Путь**

Вы человек, который впервые открыл Лунору. Идите подряд, не возвращаясь.

| Шаг | Адреса |
|---|---|
| Карточка бота, первое сообщение | `О-01` → `Б-01` |
| Онбординг: имя, место, дата, согласие | `О-02` … `О-05` |
| Расчёт | `О-06` |
| Показ, четыре слайда | `П-01` … `П-04` |
| Профиль | `Л-01` |

**Спрашивайте себя только это:**

| Вопрос |
|---|
| Понятно ли, что это и зачем, к третьему экрану? |
| Где захотелось закрыть? |
| Что попросили лишнего? Чего не хватило? |
| Первый экран профиля — это «вау» или «ну ок»? |

⚠️ **Не исправляйте формулировки.** Отмечайте `!` там, где споткнулись — не там, где написали бы иначе.

## Подход 3 · Разговор
**20 минут**

| Шаг | Адреса |
|---|---|
| Список веток, ветка, пейвол | `Ч-01` `Ч-02` `Ч-03` |
| Витрина разговора | `Р-02` |
| Запуск часа | `Ч-04` |

Переключайте **«Баланс разговора»** в панели — восемь состояний:

| Состояние | Что проверить |
|---|---|
| Бесплатные | видно, сколько осталось |
| Пусто | понятно, что делать |
| Штучные | |
| Время идёт | цена не мозолит глаза |
| Час + вопросы | выбор в меню понятен |
| Три часа | ясно, что берутся по одному |
| Сутки | формат `1 × 24 часа` читается |

| Вопрос |
|---|
| Понятно, что тратится сейчас? |
| Меню выбора нашлось само или пришлось искать? |
| Пейвол давит? |

## Что прислать

После каждого подхода — сводку из прототипа: «Замечаний: N» → «Скопировать». К строкам допишите, что не так.

```
Р-11 · Расчёт — не понял, что такое глубина
Ч-03 · Пейвол — три кнопки, глаза разбегаются
К-18 · Платёж не найден — хорошо
```

Хорошее тоже отмечайте — иначе я поправлю то, что и так работало.

## Чего в прототипе нет — не ищите

| | |
|---|---|
| **Визуальная концепция** | это проволочный макет: серые рамки, никакого образа. Замечания «скучно выглядит» применить не к чему |
| **Настоящие тексты разборов** | везде рыба, кроме посчитанных астрономических данных |
| **Welcome-страница по реферальной ссылке** | отдельным файлом `04-welcome.html` |
| **Схема экранов** | отдельным файлом `03-screen-map.html` |
