# Фабрика интерпретаций — процесс сбора источников

**Назначение:** как мы собираем материал для библиотеки блоков (таблиц интерпретаций), юридически чисто и с прослеживаемостью. Дополняет `engine-spec.md` (сама фабрика), `ENGINE-SOURCES.md` (лицензии), `ИССЛЕДОВАНИЕ-ПРАВО.md` (авторское право), `dict-numerology.md` (дисциплина ссылок).
**Дата:** 2026-11-16 · **Статус:** рабочий процесс.

---

## 0. Главный принцип: смысл — на вход, свой текст — на выход

- **Смысл / метод / «что значит признак»** — авторским правом **не охраняется** (ст. 1259 п. 5 ГК). Берём свободно из любого числа источников.
- **Текст интерпретации** из книги — **охраняется**. Покупка книги даёт право читать, **не** переносить текст в продукт или показывать пользователям.
- Поэтому источники — это **вход для смысла**, а итоговый блок пишется **нашими словами** (clean-room).
- ИИ **сводит смысл и формулирует наш текст**, но **не выбирает и не копирует чужой абзац** как финал (слабое место по методическому ревью).

> Два разных вида таблиц, не путать:
> - **Расчётные таблицы** (достоинства, управители накшатр, тяо-хоу) — факты, **выписываются** из первоисточников дословно (это не творчество, копирайт на таблицу-факт не распространяется так же).
> - **Таблицы интерпретаций** (блоки) — смысл из источников → **наш** текст. Этот документ про них.

---

## 1. Правовая рамка сбора

| Можно | Нельзя |
|---|---|
| Скачивать и использовать **общественное достояние** (текст и адаптацию) | Брать текст из книг под копирайтом в продукт |
| **Покупать** книги и читать для смысла | Систематически пересказывать чужие формулировки (переработка) |
| Хранить купленную книгу как рабочий материал **вне продукта и вне git** | Показывать пользователю пересказ значений из защищённой книги |
| Приводить **ссылку** на источник у каждой записи смысла | Давать ИИ «выбрать лучший абзац» из защищённого текста |
| | **Пиратские копии** — не берём вообще (мина под весь проект) |

**Clean-room (когда источник под копирайтом):** один человек читает книгу и выписывает **идеи/смысл своими словами** (не цитаты), другой пишет итоговый блок, **не глядя в книгу** — только по карточке смысла. Так текст заведомо наш.

## 3. Хранение и фиксация

- Первоисточники (книги, сканы) — в `research/sources/`, **вне git**, с манифестом и контрольными суммами (SHA-256). Купленное, что нельзя распространять (Александров) — помечено и в архив/репозиторий не кладётся.
- У **каждой записи смысла** — ссылка на источник (автор, издание, страница/глава). **Запись без ссылки считается непроверенной** и в блок не идёт.
- Где источники сходятся — отмечаем «согласие источников»; где расходятся — это содержание блока («традиции тут спорят»).

---

## 4. Процесс сбора — по шагам

1. **Каталог ситуаций.** Из карты консенсуса и каталога тезисов берём список паттернов (напр. для «воли»: Марс силён / слаб / напряжён / молчит). Это задаёт, **для чего** вообще нужен блок.
2. **По каждой ситуации — 2–3 источника.** Находим, что о ней говорят разные источники (в идеале разной традиции), выписываем **смысл своими словами** с ссылкой на каждый.
3. **Карточка смысла.** На ситуацию получается карточка: условие срабатывания · смысл из источника A · из B · из C · где сходятся · где спорят · запреты (здоровье/прогнозы). Защищённые источники проходят clean-room.
4. **Наш блок.** ИИ по карточке пишет НАШ текст в нашем стиле, на двух уровнях (простой + глубокий) — по смыслу, не по чужим формулировкам.
5. **Механическая проверка.** Код сверяет: блок содержит нужные сущности и **не содержит запрещённых**; есть ссылки на источники.
6. **Человек утверждает и замораживает.** Практик/оператор одобряет → блок становится статичным файлом с версией. Дальше в бесплатном слое ИИ не участвует.

---

## 5. Что получаем на выходе

Для каждой школы — **таблица смысла**: `ситуация → смысл из 2–3 источников (со ссылками) → наш блок (2 уровня) → версия`. Это и есть наполнение библиотеки (~2 800 блоков).

---

## 6. Приоритет

- Начинаем со **среза 1** (1–2 темы, напр. «Характер» + «Отношения»): по ним собираем источники и прогоняем фабрику, калибруем стиль и объём.
- Параллельно идёт **выписка расчётных таблиц** (достоинства, накшатры, тяо-хоу) — они нужны движку раньше, чем блоки.
- Полный объём источников и блоков — после калибровки на срезе 1.

---

## 7. Чего не делаем (сводка запретов)
- Не берём пиратские копии.
- Не переносим чужой текст в продукт и не показываем пересказ защищённой книги пользователю.
- Не даём ИИ выбирать/вставлять готовый абзац из источника как финал.
- Не оставляем записи смысла без ссылки на источник.
