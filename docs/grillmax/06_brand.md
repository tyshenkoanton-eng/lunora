# G6 — Бренд-идентика Луноры

**Статус гейта:** `conditional` — всё принято, кроме финального файла знака (его делает оператор). См. самоотчёт внизу.
**Документ-источник цвета:** сводка «Лунора — цветовые решения» (4 палитры), принято направление **Мятная**.

---

## 1. Платформа бренда [РЕШЕНИЕ, принято]
- **Суть:** инструмент самопознания на **проверяемом основании** («считаемость»): положение планет — факт, интерпретация — разговор. Бренд знания, которому можно доверять, не мистики.
- **Обещание:** «Поймёте себя через свою карту — по четырём школам и в разговоре с ней, а не гороскоп для всех Овнов сразу.»
- **Характер (4):** доказательный (точный) · тёплый/поддерживающий · бережный · ясный.
- **Архетип:** Мудрый проводник (не Маг — магия/предсказания отвергнуты: легал + позиционирование).
- **Чем НЕ является:** не эзотерика/мистика · не провокация/мемность · не «спидометры совместимости» · не обещания будущего.

## 2. Вербальная идентика [РЕШЕНИЕ, принято]
- **Тэглайн:** «Исследование, в котором вы познакомитесь с собой»
- **Дескриптор:** «ваш портрет по четырём школам»
- **Ключевые сообщения:**
  1. Считаемость — «Расчёт — факт, интерпретация — разговор. Четыре школы против одной».
  2. Личный разбор — «Разбор построен на вашей личной карте».
  3. Доверие — «Инструмент самопознания. Без магии и предсказаний — только ваша карта».
- **Tone of voice — на «вы»:**
  | ✅ Да | ❌ Нет |
  |---|---|
  | на «вы», тёпло, бережно, спокойная уверенность | запугивание, давление |
  | «разбор», «взгляд», «что говорит карта» | «предсказание», «прогноз событий» |
  | два уровня: просто сверху, глубже по желанию | «магия», «эзотерика», «гадание» |
  | поддержка | «изменит жизнь», «гарантированный результат», мемность |
- **Запрещённый словарь** — см. `02_problem.md` §4.5 (следствие № 901048-8 и модерации площадок).
- ⚠️ **Разнести решение «вы»** на весь пользовательский текст (позиционирование в `02_problem` написано на «ты») — на этапе копирайта (COPY_CONTRACT, G10).

## 3. Знак [направление принято; финал — за оператором]
- **Режим:** под-знак зонтичного бренда **Lunera** (не изобретаем с нуля — берём язык зонтика).
- **Тип:** комбинированный (символ + слово), **монохромный**.
- **Форма:** первая буква **L — равносторонний треугольник** (левая/правая грань ярче/сильнее нижней горизонтали); **O — ровный круг**; остальные буквы — шрифт Lunera.
- **Короткая форма (аватар/фавикон):** треугольник отдельно; читается до 34px.
- **Язык логотипа:** [ОТКРЫТО] EN (LUNORA, в семью к LUNERA) vs RU (ЛУНОРА) — решить при финале.
- **Статус:** `specified_only` — финальную отрисовку (вектор) делает оператор, пришлёт файл + шрифт Lunera. До этого знак описан, но не отрисован/не проверён на версативность.
- Черновые направления и палитра — на дизайн-канвасе: `https://claude.ai/artifact/BMhRRfuijx9dJBgGdb7RbQ`.

## 4. Фирменные цвета — Мятная [РЕШЕНИЕ, принято]
Принято направление **Мятная** (из сводки 4 палитр). **Индиго** — зафиксированная запасная для контроля.

| Роль | Светлая | Тёмная |
|---|---|---|
| paper (фон) | `#F6F2EA` | `#161D1B` |
| card | `#FFFCF7` | `#1E2925` |
| ink (текст) | `#202924` | `#EFEFE5` |
| ink-soft | `#56625A` | `#B6C3B9` |
| accent / кнопка | `#28554D` | `#A8CDBD` |
| on-accent | `#FFFCF7` | `#161D1B` |
| accent-bg | `#E4EDE7` | `#2B3C34` |

Контраст базовых пар — 13–15:1 (текст), 6–9:1 (акценты): фундамент читаемости закрыт. Полный набор — в `brand.tokens.json`.

## 5. Графический язык и движение
Right-size: направление — спокойное, «атлас/карта», тёплая бумага + зелёные действия, медный точечно. Полная проработка (паттерн, иконография, движение) — в G9 как часть UI-системы. На уровне бренда: **медный только декоративно**, не окрашивать им каждую кнопку/цену.

## 6. Делай / не делай
- ✅ Знак на чистом фоне с охранным полем; моно-версия (один цвет); тёплый акцент точечно; на «вы»; «разбор/взгляд».
- ❌ Не растягивать/наклонять знак; не класть на пёстрый фон без подложки; не красить всё зелёным (success/кнопка/декор сольются — см. G9); не «предсказание/магия»; не мемность.

## 7. Открытые вопросы → G9 (визуальная система)
Превращение палитры в систему токенов делается в G9, не здесь:
1. success отличимым от бренд-зелёного (+ подпись/иконка, не только цвет).
2. развести декор-медный (`accent`) и семантический `caution`.
3. проверить тёмную семантику success/error/caution (в части палитр были светлые значения).
4. `rule` (разделитель) ≠ `wire-line` (граница поля) — разные роли.
5. **категориальная палитра 4 школ** (различимая, доступная, всегда с названием/знаком) — ещё не задана, нужна для consensus-визуала.
