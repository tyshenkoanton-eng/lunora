# Совместимость — концепция для проектирования

**Статус:** финальная идея, готова к проектированию. Редакция от 7 ноября 2026.
**Отношение к прототипу:** заменяет нынешний единый продукт `compat` (одна
карточка с типом Любовь/Дружба/Деловое) на четыре продукта по школам, по образцу
«Прогноза на год». На момент фиксации в прототипе ещё старая модель `compat`.

## 1. Суть

Новая услуга в витрине платных разборов: совместимость пользователя с другим
человеком. Продаётся отдельно по четырём школам, как «Прогноз на год»: западная
астрология, ведическая астрология, Ба Цзы, нумерология. У каждой школы свой экран
витрины, свой метод и свой документ.

Тип отношений пользователь выбирает при вводе данных, чекбоксами: «Любовь»,
«Дружба», «Деловые отношения». От выбора зависит, какие блоки попадут в документ.
Результат: PDF на 6–9 страниц, собирается по данным в момент заказа.

## 2. Принятые решения

- Совместимость считается по каждой школе отдельно, школы не смешиваются в одном документе.
- Тип отношений не отдельный продукт, а выбор в форме заказа. Можно выбрать один тип или несколько.
- Минимум один тип обязателен. По умолчанию отмечена «Любовь», снять все галочки нельзя.
- Ведическая школа доступна только для типа «Любовь»: её метод (36 баллов) построен под брак. Остальные чекбоксы на её форме неактивны, рядом пояснялка: «в этой школе только для пары».
- Один заказ — одна цена, независимо от числа выбранных типов. Длина документа меняется (6–9 страниц).
- В результате никаких процентов и слов «несовместимы», «неблагоприятно», «судьба». Только три уровня на тему: «много лёгкости», «придётся договариваться», «будет трудно».
- Данные самого пользователя берутся из его профиля. Вводится только второй человек.
- Тип «Любовь» пишется конкретно (притяжение, близость, быт), «Дружба» и «Деловые отношения» своими акцентами. Нейтральной «универсальной» версии нет.

## 3. Витрина

Четыре экрана, один на школу, в том же каркасе, что и остальные экраны витрины:

1. Название (например, «Совместимость. Нумерология»).
2. Вступление в 2–3 предложения: что это и для кого. В одной строке называем ситуации: пара, друг, коллега.
3. «Что вы узнаете»: 3 пункта, только описание возможностей, без специальных терминов.
4. Короткий блок про ввод данных. Заголовок «Что нужно вам» **не использовать** (резко). По смыслу: что мы спросим о втором человеке.
5. Кнопка «Посмотреть пример разбора».
6. «Что в документе»: объём страниц, PDF, собирается по данным в момент заказа.
7. Кнопка «Заказать разбор».
8. Строка про оферту.

Отдельная задача на потом: написать сами тексты экранов. Здесь только каркас и ограничения.

## 4. Форма заказа

**Поля:**
- Данные второго человека (набор зависит от школы, см. раздел 5).
- Чекбоксы «Любовь», «Дружба», «Деловые отношения».

**Поведение:**
- Минимум один чекбокс. «Любовь» отмечена сразу.
- Для ведической школы доступна только «Любовь», остальные неактивны, с пояснением.
- Нужно согласие пользователя, что он вводит данные другого человека с его ведома. Формулировку и хранение проверить с юристом (ПД третьего лица).

## 5. Какие данные нужны

| Школа | Данные второго человека | Если чего-то нет |
|---|---|---|
| Западная | Дата; время и место рождения необязательны | Луна приблизительная, дома и восходящий знак не считаются. В документе помечено |
| Ведическая | Дата, время и место рождения обязательны | Без них не продаём: положение Луны определяется неточно |
| Ба Цзы | Дата; время и часовой пояс места рождения желательны | Столп часа не считается, помечено. Границы сезонов с учётом часового пояса, даты не зашивать |
| Нумерология | Дата и полное ФИО (имя, отчество, фамилия) | Без отчества считаем по тому, что есть, и пишем об этом |

**Важно:** для дружбы и работы пользователь часто не знает время рождения другого
человека. Документ обязан работать по одной дате и честно отмечать приблизительность.

## 6. Правила расчёта по школам

### 6.1 Нумерология (делать первой, расчёт готов)

Четыре пары чисел у двух людей. Названия простыми словами, термины один раз в «Как посчитано»:
- **Основа:** число жизненного пути по дате рождения.
- **Что вы умеете:** число выражения (все буквы полного ФИО).
- **Чего вы хотите:** число души (гласные).
- **Как вас видят:** число личности (согласные).

Таблица букв: А=1, Б=2, … З=9, затем цикл (И=1, Й=2, К=3 …). Ь и Ъ не считаются.
Гласные: А Е Ё И О У Ы Э Ю Я. Остальные согласные. Числа сводятся к одной цифре,
**11 и 22 не сводятся** (11 — усиленная двойка, 22 — усиленная четвёрка). Считается
всё ФИО. Число жизненного пути: день + месяц + год, каждый сведён, итог сведён (с
сохранением 11 и 22).

**Тестовые данные (проверены вручную и в коде):**
- Антон Юрьевич Тыщенко: все буквы 88 → 7, гласные 35 → 8, согласные 53 → 8.
- Антон Юрьевич Стальмахов: 82 → 1, 29 → 11, 53 → 8.
- Дата 04.02.1984: 4 + 2 + 22 = 28 → 10 → 1.
- Фамилия Ковалёва (Ё=7): 29 → 11, гласные 16 → 7, согласные 13 → 4. Ковалева (Е=6): 28 → 1, гласные 15 → 6, согласные 13 → 4.

Открытое правило: как считать Ё. Пока обязательное требование: в документе всегда
показывать, с какой буквой считали.

Чтение пар: из сравнения каждой пары — «лёгкость / договариваться / трудно» по теме. Акценты по типам — раздел 7.

### 6.2 Ба Цзы

Написание: «Ба Цзы», без дефиса. Сравнивается:
- Отношение главных стихий двоих (одна и та же, поддерживает, подавляет).
- Нижняя часть дня рождения: ритм близости. Только для типа «Любовь».
- Что одной карте не хватает, а другая даёт.
- Совпадения и столкновения по столпам. Столкновение — трение и движение, не приговор.
- Отдельная строка: притяжение отдельно от совместимости (можно тянуться к тому, с кем тяжело).

Формат: вывод наверху, затем компактная таблица «пункт / результат / как читать». Без
единой оценки. Язык нейтральный по полу и составу пары.

### 6.3 Западная астрология

Планеты двух карт: Солнце, Луна, Меркурий, Венера, Марс, Сатурн (при необходимости
Юпитер). Узкие аспекты (орб < 3°) весомее. Группировка по темам, не списком аспектов:
- Притяжение.
- Общение.
- Эмоциональная опора.
- Надёжность надолго.

Если время известно — наложение домов и общая карта пары. Если нет — Луна
приблизительная, дома не считаются, явно помечается. Список аспектов с терминами —
только в «Как посчитано».

### 6.4 Ведическая астрология (только «Любовь»)

Система из 8 категорий, максимум 36 баллов (веса 1–8). По лунному знаку и накшатре
обоих. Самые весомые: Нади (8) и Бхакут (7). Ориентиры: от 18 приемлемо, от 24
хорошо, от 32 отлично. Названия областей у источников различаются, трактовку
фиксировать после экспертной проверки.

Подача:
- Общий балл показываем (фирменный результат школы), объясняем простыми словами, без санскрита (термины — в «Как посчитано»).
- Восемь категорий переводим в обычные темы (набросок: взгляды на жизнь, кто ведёт, общая удача, близость, понимание, характер, эмоциональная связь, здоровье и энергия пары).
- Никаких «союз неблагоприятен», «несовместимы». Оговорка: балл — первый фильтр, а не приговор.
- Манглик-дошу в первой версии не включаем (пугающая тема). Возможен мягкий вариант позже.

## 7. Что включается по типам

| Школа | Любовь | Дружба | Деловые отношения |
|---|---|---|---|
| Западная | Венера и Марс (притяжение, близость); Луна (эмоциональная опора) | Луна и Меркурий (лёгкость, общие интересы) | Меркурий, Марс, Сатурн (договорённости, споры, ответственность) |
| Ведическая | Все восемь категорий | Не предлагается | Не предлагается |
| Ба Цзы | Нижняя часть дня (ритм близости), поддержка стихий, притяжение и совместимость | Главные стихии, поддержка и нехватка | Главные стихии, поддержка и нехватка, роли |
| Нумерология | Как видят (первое притяжение), чего хотите (надолго), основа | Чего хотите, как видят | Что умеете, основа |

**Ограничение:** раскладка по типам для западной и нумерологии — рабочее
предложение, готовых образцов нет, нужна проверка специалистом. Для ведической
устоявшегося метода для дружбы и работы не нашли.

## 8. Структура документа (6–9 страниц)

1. **Главное.** Три строки: что вас связывает, где будет трудно, на что опереться. При нескольких типах — таблица «тип отношений × уровень».
2. **Что между вами.** Блок на каждый выбранный тип, содержание по школе (разделы 6 и 7).
3. **Что вы даёте друг другу.** Что получает каждый и чего ждёт.
4. **Где будут споры.** 2–3 конкретные ситуации и что с ними делать.
5. **Что делать вместе.** Три коротких пункта под выбранные типы.
6. **Как посчитано.** Данные, формулы, допущения, что приблизительно, оговорка про склонности, а не предсказание.

**Правила сборки:** пустые поля и блоки не выводятся; блоки не повторяют друг друга;
приблизительные выводы помечены; длина зависит от числа типов.

## 9. Язык и стиль

- Литературно, но гладко. Простые слова, меньше пафоса и «ИИшных» оборотов.
- На экранах и в основном тексте никаких терминов — только описание. Термины один раз в «Как посчитано».
- Три уровня результата: «много лёгкости», «придётся договариваться», «будет трудно». Без процентов и баллов (кроме общего балла ведической школы).
- Не обещаем судьбу и не говорим «вам нельзя быть вместе».
- Единые названия: «Ба Цзы» без дефиса; сферы в других разборах — «Работа и деньги / Отношения / Здоровье» (здесь не используются, но не менять).

## 10. Крайние случаи

- Время рождения неизвестно: см. раздел 5, всё приблизительное помечено.
- Нет отчества у второго человека: считаем без него, указано.
- Одинаковые числа или знаки: не «идеально», а зеркальность (поддерживает, но может повторять слабые стороны).
- Мастер-числа 11 и 22: по правилу из 6.1.
- Один человек в двух ролях (друг и коллега): оба блока и сводная таблица.

## 11. Критерии приёмки

- Цифры нумерологического расчёта совпадают с тестовыми из 6.1.
- В форме ведической школы активна только «Любовь».
- Нельзя оформить заказ без выбранного типа.
- В документе нет процентов и слов из запрещённого списка (раздел 9).
- Без времени рождения — пометка о приблизительности, дома и столп часа не выводятся.
- Документ с одним типом короче, чем с тремя, без пустых блоков.

## 12. Открытые вопросы

1. Правило для Ё (раздел 6.1).
2. Цена: подтвердить одну цену независимо от числа типов.
3. Манглик-доша: пока исключена.
4. Квадрат Пифагора и матрица судьбы в нумерологии: популярны в России, по одной дате, отдельная методика. В первую версию не включать.
5. Время рождения для ведической школы: обязательное или допустить без него.
6. Юридическая проверка ввода данных третьего лица.
7. Экспертная проверка раскладки по типам (раздел 7) и трактовок восьми категорий ведической школы.

## 13. Порядок внедрения (рекомендация)

1. Нумерология: расчёт готов, нужны дата и ФИО.
2. Ба Цзы: нужен календарь сезонов и расчёт столпов.
3. Западная: нужны планетные позиции.
4. Ведическая: нужны накшатры и расчёт 36 баллов, самая тяжёлая по вводу.

Для каждой школы: сначала один образец документа на реальной паре, затем экран витрины.

## 14. На чём основано

Исследование конкурентов (ноябрь 2026):
- Платных русскоязычных документов по совместимости не найдено, есть бесплатные приложения и калькуляторы.
- Нумерология (Decoz): 16 страниц, профиль каждого и сравнение, без оценок и вердикта.
- Западная (Astrotheme): 77+ страниц, четыре шкалы 0–100 %, аспекты. Cafe Astrology: четыре главы, без оценок.
- Ведическая (Prokerala): ~17 страниц, много терминов, жёсткий вердикт «союз неблагоприятен» — так делать не надо.
- Ба Цзы: лучший образец (MyBaziReport) — вывод сверху и компактная таблица без оценок.
- Деление на типы: The Pattern (категория в одном разделе) и Cafe Astrology (отдельный отчёт для дружбы и работы).
