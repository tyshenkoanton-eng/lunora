**Ключевой результат сверки.** При истинных геометрических положениях + средних узлах наши
сидерические долготы совпадают с JH с **постоянным сдвигом −55,8″** (разброс по телам ±0,3″,
включая средний узел). Этот сдвиг — чистая разница айанамши: JH True Chitrapaksha, у нас
Лахири №1 (средняя, §2.7). Разница отнесена к «настройкам эталона», **не подгоняется**
(указание Антона). Все дискретные значения (раши, накшатра, пада, бхава, лагна, D9, D10,
последовательность даш) совпали с JH по всем трём картам — сдвиг 56″ нигде не пересекает
границу (кроме пограничного кейса B-Сурья, см. ниже, где знак всё равно совпадает).

Если бы движок считал по видимым положениям (с аберрацией, как §2.7 для западной), появился бы
дополнительный переменный сдвиг до ~20″ по телу — поэтому ведический кадр берёт геометрические
положения (это и предупреждал Антон).

- **Айанамша (все карты, все тела):** постоянный −55,8″ (Лахири №1 средняя vs JH True
  Chitrapaksha). Класс «настройки эталона». Дискретные значения не затрагивает.
- **Длина года даш (все карты):** наши даты МД на ~4 суток позже JH (Y=365,25 vs true sidereal

  `can_vote:false`, продукт — до года; год начала каждой МД совпадает с JH.
