# Лунора — правила разработки (читается Claude Code в каждой сессии)

Мультисистемный астрологический оракул — Telegram Mini App. Персональные разборы по 4 системам (западная, ведическая/Джйотиш, китайская/Ба-Цзы, нумерология). Ядро отличия — **«считаемость»**: расчёт по карте — факт, интерпретация — разговор.

## Текущая фаза
Discovery (L0) по методологии ГРИЛЛ МИ МАКС **закрыт** — вердикт **GO с условиями**. Мы в **L1 (реализация)**.
- **Перед кодингом** смотри текущий слайс в `docs/grillmax/16_roadmap.md` (§5 — порядок L1).
- **Первый слайс S1 — спайк корректности ядра** (непереносимо): движки на golden-наборах, время/пояса, стоимость LLM, пробная оплата. Пока S1 не доказан — не строить фичи поверх.

## Стек
- Бэкенд: Python 3.12, FastAPI, aiogram 3, SQLAlchemy (async), PostgreSQL, Redis. Caddy, Docker Compose.
- Фронтенд: React 19, TypeScript, Vite (`frontend/`).
- Тесты: pytest + pytest-asyncio. Линт/формат: ruff.

## Жёсткие правила (из Discovery — не нарушать)
1. **Фронтенд строго token-driven (ADR-003).** Все цвета/отступы/шрифты — из `docs/grillmax/tokens.json`; экраны собираются из переиспользуемых компонентов. **Ни одного захардкоженного цвета/пикселя** в разметке. Это гарантия, что дизайн доводится параллельно и впрыгивается через токены.
2. **Корректность ядра — тестами (test-first).** Каждый движок проверяется на golden-наборах (ловим ошибки прототипа: пропуск Солнца, высшие планеты по знаку, год Ба-Цзы на границе — см. `docs/grillmax/04_product.md`). Красный тест = не мёржим.
3. **Оплата: внутри Telegram — только Stars (`XTR`)** (решение D-121). СБП/ЮKassa — только вне Telegram (веб/MAX). Повтор оплаты не создаёт второй платёж (идемпотентность).
4. **Приватность (152-ФЗ).** В аналитику и зарубежный LLM **не уходят ПДн** (дата рождения, ФИО, тексты вопросов): в LLM — только вычисленные градусы + текст; в аналитику — только события воронки без ПДн.
5. **Голос продукта — на «вы»**, тёпло, без «предсказаний/магии/гарантий». Запрещённый словарь — `docs/grillmax/02_problem.md` §4.5.
6. **Бюджет LLM** — библиотека детерминированных интерпретаций + LLM только на синтез + дешёвая модель на прогнозы (R-05). Следить за стоимостью на пользователя.

## Команды
```bash
docker compose up --build        # поднять окружение
pytest -q                        # тесты бэкенда
ruff check . && ruff format .    # линт + формат
cd frontend && npm run dev       # фронт в деве
```
